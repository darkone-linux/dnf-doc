## Ajouts

- **home-games** : EnableGnome et nettoyage des conditions
- **idm** : passe kanidm en 1.12, 1.11 arrive en fin de vie le 2026-12-01
- **idm** : active la sauvegarde en ligne de kanidm, 7 dumps nocturnes conservés
- **supertuxkart** : EnableDirectLink, jouer via un câble Ethernet direct
- **luks** : les passerelles signalent leur adresse WAN au HCS
- **network** : option de switch logiciel, le réseau du parc passe dans network.nix
- **just** : drv-diff prouve qu'un refactor du framework laisse les hôtes inchangés
- **install** : réessaie nixos-install en cas d'échec de téléchargement
- **install** : install-here reprend sur le disque conservé avec DNF_RESUME=1
- **iso** : menu sur tty1, nouveau réseau ou rejoindre un réseau existant
- **install** : témoin de sauvegarde, la page d'accueil avertit quand les clés ne sont pas sauvegardées
- **just** : la release s'exécute sans intervention avec YES=1

## Modifications

- **overlays** : une seule liste ordonnée dans lib/overlays/default.nix
- **activation** : un seul module applique les déclencheurs du registre pour chaque profil
- **lib** : la plomberie du flake passe dans lib/flake/, images et liste de systèmes partagées
- **flake** : un seul nixpkgsFor pour chaque sortie du framework

## Documentation

- **registry** : Config/modules.nix ne contient que des valeurs littérales
- **dev** : supprime les renvois vers des fichiers d'agent non publiés et des chemins obsolètes
- **comments** : supprime les renvois vers des specs privées dans le code publié
- **activation** : l'en-tête du helper n'est plus lié aux mixins d'hôte
- **backports** : retirer l'overlay geneweb retire aussi son entrée de liste
- **links** : les liens de la référence des modules pointent vers les pages de module
- **install** : les README de template pointent vers les nouvelles feuilles de doc
