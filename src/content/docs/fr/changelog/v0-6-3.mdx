## Ajouts

- **install** : refuse une passerelle dont le réseau de la machine chevauche sa zone
- **iso** : affiche les cartes réseau et les disques installables sur l'écran de l'installateur
- **install** : l'installation complète marque une pause pour recâbler derrière une nouvelle passerelle
- **iso** : le code d'appariement sur l'installateur générique permet à l'administrateur de le saisir
- **install** : appaire l'installateur générique avec son code, épingle sa clé d'hôte
- **install** : host-info sonde les cartes, les disques et le MAC de la carte routée
- **admin** : commandes darkone et dnf-generator sur les hôtes d'administration
- **install** : l'installation prend sa confirmation et sa clé d'hôte depuis darkone
- **admin** : la page d'accueil marque l'étape 2 comme terminée dès que la zone dispose d'une passerelle
- **veloren** : activation
- **oxicloud** : envoie les résultats des tâches par courriel à la boîte de l'administrateur
- **template** : fournit statix.toml avec repeated_keys désactivé
- **outline** : applique PKCE via la découverte OIDC

## Corrections

- **install** : la passerelle de sa zone n'a pas besoin de mac, ignore l'avertissement de résolution
- **install** : l'installation complète attend le retour de l'hôte après son dernier redémarrage
- **sso** : Oauth2-proxy conserve les sessions dans un Redis local, met fin à la boucle de connexion
- **imagery** : utilise le paquet sweethome3d renommé
- **ai** : Open-webui repasse sur unstable, retire l'épinglage stable et le contournement fpdf2
- **fleet-update** : ajoute shellcheck, yq-go et gawk au PATH des mises à jour automatiques
- **terminal** : un seul presse-papiers pour le clic milieu, le clic droit et Ctrl+V
- **openclaw** : arrête la boucle de redémarrage de la passerelle sur une erreur de configuration
- **gnome** : masque xterm via hidden-apps, aucune entrée de bureau dupliquée
- **release** : le train conditionne dnf-generator à ses propres recettes ci et audit
