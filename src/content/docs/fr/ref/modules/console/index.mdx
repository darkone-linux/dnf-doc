**Un module d'applications CLI** installe des applications en terminal et leur configuration optimisée pour DNF.

| Module | Rôle |
|---|---|
| [`git`](/fr/ref/modules/console/git/) | Un environnement git préconfiguré. |
| [`zsh`](/fr/ref/modules/console/zsh/) | Une installation complète de zsh avec alias, bindkeys et invite de commande optimisée. |
