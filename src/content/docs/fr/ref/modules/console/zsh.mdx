Une installation complète de zsh avec alias, raccourcis clavier (bindkeys) et invite de commande optimisée.

:::tip[Quelques raccourcis]
Général :
- `l`, `la`, `ll` : ls avec options
- `vz` : vim + fzf
- `treef` : arbre avec fichiers (eza)
- `treed` : arbre des seuls dossiers (eza)
- `locate` : recherche localsearch (si localsearch est installé à la place de locate)

Pour le profil admin nix/dnf :
- `nx` : cd /etc/nixos
- `nf` : nixfmt
- `nc` : deadnix
- `dnf` : cd ~/dnf
- `mrproper` : nix-collect-garbage(s) + switch-to-conf boot
:::

## Options

* **enable** `bool` Environnement ZSH
* **enableForRoot** `bool` Configuration ZSH de Home Manager pour root

```nix
darkone.console.zsh = {
  enable = false;
  enableForRoot = false;
};
```
