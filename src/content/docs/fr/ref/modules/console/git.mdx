Un environnement git préconfiguré.

:::tip[Raccourcis git]
- `git hdf` (diff de l'historique) : sélectionner un commit pour afficher le diff.
- `git tree` : arbre de l'historique.
- `git tre` : historique avec les fichiers.
- `git treee` : historique avec les messages de commit.
- `git hist` : alternative à l'arbre.
:::
