Configuration matérielle et secure boot (R1–R7). (wip)

Couvre le Secure Boot UEFI (R3), lanzaboote, le mot de passe du chargeur de démarrage (R5), les UKI signées (R6) et l'IOMMU (R7). R1 et R2 (matériel et firmware) sortent du périmètre NixOS et produisent seulement une note dans le rapport.

:::caution[Activation]
L'option `enable` suit `darkone.system.security.enable` par défaut.
Les règles (Rxx/Cxx) sont activées selon le niveau, la catégorie et les exclusions définis dans `darkone.system.security` (via `isActive`).
:::

:::caution[R3/R4 : Secure Boot]
L'intégration lanzaboote exige un enrôlement initial physique des clés (`sbctl enroll-keys`). R4 (remplacement des clés Microsoft) présente un risque de rendre la machine inutilisable si elle ne permet pas la restauration.
:::

:::caution[R7 : IOMMU]
Peut provoquer des plantages avec certains GPU ou Thunderbolt&nbsp;; surcoût d'E/S d'environ 5 à 15&nbsp;% sur des baies NVMe à très fort débit.
:::

## Options

* **enable** `bool` Active le secure boot ANSSI : Secure Boot, IOMMU (R1–R7).

```nix
darkone.security.preboot.enable = false;
```
