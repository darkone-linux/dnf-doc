Gestion des paquets et mises à jour (R58–R61). (wip)

Couvre l'installation du strict nécessaire (R58), les dépôts de confiance (R59), les dépôts durcis (R60&nbsp;: linux_hardened) et les mises à jour régulières (R61).

:::caution[Activation]
L'option `enable` suit `darkone.system.security.enable` par défaut.
Les règles (Rxx/Cxx) sont activées selon le niveau, la catégorie et les exclusions
définis dans `darkone.system.security` (via `isActive`).
:::

:::caution[R59 : allow-import-from-derivation=false]
Casse certains flakes complexes (Haskell, Python lourd avec générateurs Nix).
Documenter les exceptions dans nix.settings.
:::

:::caution[R60 : linux_hardened]
Le noyau linux_hardened peut avoir un retard d'une version mineure sur nixpkgs-unstable.
Les modules tiers (NVIDIA, ZFS) ne sont pas garantis compatibles.
:::

## Options

* **enable** `bool` Active la gestion des paquets ANSSI (R58–R61).
* **trustedSubstituters** `listOf str` Liste d'autorisation des caches binaires Nix autorisés (R59).
* **trustedPublicKeys** `listOf str` Clés publiques des caches binaires autorisés (R59).
* **allowedUris** `listOf str` Liste d'autorisation par préfixe des URI récupérables pendant l'évaluation (R59).
  Restreint builtins.fetch* / flake inputs aux miroirs internes.
  Une liste vide désactive la restriction.
* **maxSystemPackages** `nullOr int` Seuil souple sur le nombre de paquets système (R58).
  Émet un avertissement d'évaluation au dépassement ; null désactive la vérification.

```nix
darkone.security.packages = {
  enable = false;
  trustedSubstituters = [ ];
  trustedPublicKeys = [ ];
  allowedUris = [ ];
  maxSystemPackages = 200;
};
```
