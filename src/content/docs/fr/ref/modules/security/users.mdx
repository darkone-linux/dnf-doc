Comptes utilisateurs et authentification (R30–R36). (wip)

Couvre les comptes inutilisés (R30), la politique de mot de passe (R31), le verrouillage après inactivité (R32), la responsabilité des administrateurs (R33), les comptes de service (R34), les comptes de service uniques (R35) et umask (R36).

:::caution[Activation]
L'option `enable` suit `darkone.system.security.enable` par défaut.
Les règles (Rxx/Cxx) s'activent selon le niveau, la catégorie et les exclusions définis dans `darkone.system.security` (via `isActive`).
:::

:::caution[R30 : mutableUsers=false]
NixOS n'autorise plus les `passwd`/`useradd` ad hoc. Toute modification de compte demande un déploiement NixOS complet (`colmena apply`).
:::

:::caution[R36 : umask 0077]
Casse la collaboration de groupe (`/srv/share`). Documenter que `chmod g+rwx <file>` est nécessaire pour le partage de groupe.
:::

## Options

* **enable** `bool` Active la gestion des comptes ANSSI (R30–R36).
* **idleTimeout** `ints.unsigned` Secondes avant la fermeture d'un shell de connexion inactif (R32, `TMOUT`). `0` supprime totalement le délai du TTY ; le verrouillage d'inactivité GNOME n'est pas affecté. Les postes qui gardent des terminaux longue durée (ferme de compilation, outils d'agents) mettent `0`.

```nix
darkone.security.users = {
  enable = false;
  idleTimeout = 600;
};
```
