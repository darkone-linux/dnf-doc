**Un module de sécurité** renforce le système, ses programmes et ses fonctionnalités.

| Module | Rôle |
|---|---|
| [`complement`](/fr/ref/modules/security/complement/) | Mesures complémentaires transversales : annexe A (C1–C12). (wip) |
| [`filesystem`](/fr/ref/modules/security/filesystem/) | Partitionnement, arborescence et permissions des fichiers (R28–R29, R50–R57). (wip) |
| [`integrity`](/fr/ref/modules/security/integrity/) | Intégrité du système de fichiers : HIDS (R76–R77). (wip) |
| [`journaling`](/fr/ref/modules/security/journaling/) | Journalisation et auditd (R71–R73). (wip) |
| [`kernel-build`](/fr/ref/modules/security/kernel-build/) | Configuration statique du noyau : nécessite une recompilation (R15–R27). (wip) |
| [`kernel-params`](/fr/ref/modules/security/kernel-params/) | Configuration dynamique du noyau : paramètres de démarrage et sysctl (R8–R14). (wip) |
| [`mac`](/fr/ref/modules/security/mac/) | Contrôle d'accès obligatoire : MAC (R37, R45–R49). (wip) |
| [`mta`](/fr/ref/modules/security/mta/) | Gestion locale du courrier (R74–R75). (wip) |
| [`network`](/fr/ref/modules/security/network/) | Services réseau : isolation et supervision (R78–R80). (wip) |
| [`nss`](/fr/ref/modules/security/nss/) | NSS : bases de données d'utilisateurs distantes (R69–R70). (wip) |
| [`packages`](/fr/ref/modules/security/packages/) | Gestion des paquets et mises à jour (R58–R61). (wip) |
| [`pam`](/fr/ref/modules/security/pam/) | PAM : authentification et stockage des mots de passe (R67–R68). (wip) |
| [`preboot`](/fr/ref/modules/security/preboot/) | Configuration matérielle et démarrage sécurisé (R1–R7). (wip) |
| [`services`](/fr/ref/modules/security/services/) | Durcissement des services systemd (R62–R66). (wip) |
| [`sudo`](/fr/ref/modules/security/sudo/) | Durcissement de sudo (R38–R44). (wip) |
| [`users`](/fr/ref/modules/security/users/) | Comptes utilisateurs et authentification (R30–R36). (wip) |
