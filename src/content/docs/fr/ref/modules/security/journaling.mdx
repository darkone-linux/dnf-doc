Journalisation et auditd (R71–R73). (en cours)

Couvre la journalisation persistante avec transfert TLS (R71), les journaux dédiés par service (R72) et auditd avec les règles de l'ANSSI (R73).

:::caution[Activation]
L'option `enable` suit `darkone.system.security.enable` par défaut.
Les règles (Rxx/Cxx) sont activées selon le niveau, la catégorie et les exclusions définies dans `darkone.system.security` (via `isActive`).
:::

:::caution[R71 : Seal=yes]
`Seal=yes` nécessite `journalctl --setup-keys` (clé d'audit hors bande).
Sans cette clé, l'intégrité du journal ne peut pas être vérifiée.
:::

:::caution[R73 : auditd immuable]
La configuration `audit.rules = [ "-e 2" ]` rend auditd immuable : toute modification de règle nécessite un redémarrage. Tester en préproduction avant le déploiement.
:::

## Options

```nix
darkone.security.journaling.enable = false;
```
