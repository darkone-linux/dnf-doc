Durcissement sudo (R38–R44). (wip)

Couvre le groupe sudo dédié (R38), les directives sudo durcies (R39), la restriction des cibles non root (R40), la limitation de NOEXEC (R41), l'interdiction des négations (R42), la spécification explicite des arguments (R43) et l'usage de sudoedit (R44).

:::caution[Activation]
L'option `enable` suit `darkone.system.security.enable` par défaut.
Les règles (Rxx/Cxx) sont activées selon le niveau, la catégorie et les exclusions
définis dans `darkone.system.security` (via `isActive`).
:::

:::caution[R39 — `noexec` et `requiretty` abandonnés]
Les deux sont incompatibles avec un déploiement piloté par un agent : colmena élève
ses droits avec `sudo -H --` via SSH (sans PTY, `requiretty` refuse), et
`switch-to-configuration` lance des processus enfants (`noexec` le bloque).
La traçabilité repose donc plutôt sur `use_pty` + `log_input`/`log_output`.
:::

:::caution[R39 — rootpw]
`rootpw` impose un mot de passe root partagé entre administrateurs.
Préférez `targetpw` ou `runaspw` selon la politique de l'équipe.
:::

## Options

* **enable** `bool` Active le durcissement sudo ANSSI (R38–R44).
* **allowedRootRules** `listOf str` Règles sudo autorisées à cibler root (R40). Les autres doivent cibler un compte de service.

```nix
darkone.security.sudo = {
  enable = false;
  allowedRootRules = [ ];
};
```
