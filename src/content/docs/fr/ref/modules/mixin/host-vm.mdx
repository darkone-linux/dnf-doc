## Options

* **enableVirtualbox** `bool` Client Virtualbox
* **enableQemu** `bool` Client Qemu/KVM
* **enableXen** `bool` Client Xen

```nix

  enableVirtualbox = false;
  enableQemu = false;
  enableXen = false;
};
```
