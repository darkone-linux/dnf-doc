Profil pour utilisateurs avancés (informaticiens, développeurs, administrateurs).

:::note[Profil hôte ou profil Home&nbsp;?]
Ce module active des fonctionnalités pour tous les utilisateurs du système.
Utilisez les profils HomeManager pour fournir des logiciels adaptés à chaque utilisateur (admin, avancé, étudiant, enfant, adolescent, etc.).
:::

{/* t:p 7bed66fd52799fb5fe77bc4f5dd84d54739269eb5b2d5caf4bb61f431fc3e923 */}
## Options

* **enable** `bool` Utilisateur avancé (admin système, développeur)

```nix
darkone.profile.advanced.enable = false;
```
