**Un module mixin** définit une collection de modules standard avec une configuration commune cohérente.

| Module | Rôle |
|---|---|
| [`host.ai-space`](/fr/ref/modules/mixin/host-ai-space/) | Espace IA : hôte sans interface exécutant les agents d'un espace (propriétaire + membres). |
| [`host.desktop`](/fr/ref/modules/mixin/host-desktop/) | Une configuration bureau complète avec gnome, multimédia et bureautique. |
| [`host.gateway`](/fr/ref/modules/mixin/host-gateway/) | La passerelle / routeur principal d'une zone de réseau local. |
| [`host.hcs`](/fr/ref/modules/mixin/host-hcs/) | Le serveur de coordination headscale principal. |
| [`host.laptop`](/fr/ref/modules/mixin/host-laptop/) | Configuration bureau + outils &amp; réglages spécifiques aux portables. |
| [`host.minimal`](/fr/ref/modules/mixin/host-minimal/) | Toute configuration d'hôte repose sur cette configuration minimale. |
| [`host.portable`](/fr/ref/modules/mixin/host-portable/) | Configuration portable pour une clé USB amorçable contenant une machine NixOS du réseau local. |
| [`host.server`](/fr/ref/modules/mixin/host-server/) | Configuration renforcée pour serveurs (minimale, sans veille, watchdog...). |
| [`host.umi`](/fr/ref/modules/mixin/host-umi/) | Profil d'hôte : poste UMI (Unified Multimodal Input), utilisable sans clavier ni souris. |
| [`host.vm`](/fr/ref/modules/mixin/host-vm/) | Outils invités pour machines virtuelles. |
| [`profile.advanced`](/fr/ref/modules/mixin/profile-advanced/) | Profil pour utilisateurs avancés (informaticiens, développeurs, administrateurs). |
