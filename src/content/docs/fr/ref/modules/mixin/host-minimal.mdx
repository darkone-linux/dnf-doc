Chaque configuration d'hôte repose sur cette configuration minimale.

:::caution[Déclaration des services]
Un certain nombre de services (immich, nextcloud, forgejo, etc.) peuvent être déclarés dans
`etc/config.yaml` de chaque hôte, quel que soit son type (serveur, portable,
poste de travail, etc.). **Il est conseillé de les déclarer dans le fichier yaml pour que
le service soit visible sur l'ensemble du réseau&nbsp;!**
:::

{/* t:p fc01b15d4273c22138aa3fd8fcb942d595b9f8c6e3af487388c29774acbcaa5e */}
## Options

* **enable** `bool` Configuration d'hôte minimale
* **secure** `bool` Privilégier les options plus sûres (désactiver les utilisateurs mutables...)

```nix
darkone.host.minimal = {
  enable = false;
  secure = false;
};
```
