The main headscale coordination server.

:::tip[Un serveur headscale prêt à l'emploi !]
Le réseau est configuré dans le fichier `etc/config.yaml`.
Les services activés (authentification, etc.)
sont configurés automatiquement avec une plomberie réseau cohérente sur votre
réseau global.

Alias zsh « h » pour « headscale ».
:::

:::caution[SSH public]
Le port 22 est ouvert sur toutes les interfaces, Internet compris — seul hôte de la
flotte dans ce cas : il héberge le plan de contrôle du tailnet, donc l'accès
ne doit pas dépendre du tailnet.
:::

## Options

* **enable** `bool` Activer le serveur de coordination headscale
* **enableClient** `bool` Activer le client tailscale sur le nœud HCS (recommandé pour héberger des services)

```nix
darkone.host.hcs = {
  enable = false;
  enableClient = true;
};
```
