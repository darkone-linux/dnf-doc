### &#x1F3E0; darkone.home.advanced

Profil d'accueil pour les utilisateurs avancés (informaticiens, développeurs, administrateurs).

:::note[Clés SSH depuis Vaultwarden]
`enableVaultwardenSsh` transforme `rbw` en agent SSH : les clés privées restent
dans le coffre de l'utilisateur (chiffrement de bout en bout), jamais en clair
sur disque ni dans sops. L'utilisateur lance `rbw unlock` une fois par session.
:::

* **enable** `bool` Activer les fonctionnalités utilisateur avancées
* **enableTools** `bool` Outils variés pour les utilisateurs avancés
* **enablePhoneTools** `bool` Outils pour smartphone (scrcpy)
* **enableAdmin** `bool` Activer les fonctionnalités administrateur (réseau, outils système)
* **enableNixAdmin** `bool` Activer les fonctionnalités d'administration nix
* **enableDnfDeveloper** `bool` Activer tous les outils pour DNF Codev Developer
* **enableDeveloper** `bool` Activer les outils développeur
* **enableEssentials** `bool` Outils fréquemment utilisés
* **enableVaultwardenSsh** `bool` Agent SSH adossé au coffre Vaultwarden de l'utilisateur (rbw). Ne pas activer sur
  un hôte joint via `ssh -A` : l'agent local masquerait celui relayé

```nix
darkone.home.advanced = {
  enable = false;
  enableTools = false;
  enablePhoneTools = false;
  enableAdmin = false;
  enableNixAdmin = false;
  enableDnfDeveloper = false;
  enableDeveloper = true;
  enableEssentials = true;
  enableVaultwardenSsh = false;
};
```

### &#x1F3E0; darkone.home.ai

Outils de codage IA et utilitaires associés.

:::note[Drapeaux]
- `darkone.home.ai.enable` : paquets utilitaires (aichat, llm, fabric-ai, gh,
  lazygit, direnv, outils Rust et qualité de code) et les drapeaux d'agent ci-dessous.
- `darkone.home.ai.enable{Claude,OpenCode,Codex,Antigravity,Aider,Goose}` :
  un agent de codage IA chacun.
- `darkone.home.ai.preferLocal` : OpenCode utilise par défaut le modèle ollama
  local sur un hôte `darkone.service.ai`.
:::

:::tip[Câblage par hôte]
Sur un hôte ollama local (`darkone.service.ai`) : `gollama` et la CLI
`ollama`, et Aider revient au modèle local quand Claude est désactivé.

La CLI GitHub (`gh`) et la CLI Copilot (`copilot`) sont installées. Claude Code
applique une matrice de permissions autoriser/demander/refuser et un hook de
gouvernance RTK sur les appels Bash.
:::

:::caution[settings.json modifiable]
Claude Code et Antigravity CLI réécrivent leur propre `settings.json` : un
lien symbolique en lecture seule les casse, et fait échouer le prochain switch
sur le `.bkp`. Le socle Nix est fusionné par jq dans un fichier MODIFIABLE à
chaque switch à la place ; les clés d'exécution (plugins, espaces de travail
de confiance) sont préservées.
:::

* **enable** `bool` Activer les outils IA et les utilitaires associés
* **enableClaude** `bool` CLI Claude Code
* **enableOpenCode** `bool` Agent IA terminal OpenCode
* **enableCodex** `bool` CLI OpenAI Codex
* **enableAntigravity** `bool` CLI Google Antigravity
* **enableAider** `bool` Programmation en binôme IA avec Aider
* **enableGoose** `bool` Agent de codage IA Goose (Block Inc.)
* **preferLocal** `bool` Préférer les modèles locaux plutôt que cloud

```nix
darkone.home.ai = {
  enable = false;
  enableClaude = false;
  enableOpenCode = false;
  enableCodex = false;
  enableAntigravity = false;
  enableAider = false;
  enableGoose = false;
  preferLocal = false;
};
```

### &#x1F3E0; darkone.home.audio

Outils et effets audio.

Installe l'encodeur MP3 (`lame`) et, avec GNOME, un lecteur audio
(`vlc`), puis ajoute les éditeurs et effets (`audacity`, `easyeffects`) quand
`enableTools` est défini. La réduction de bruit en temps réel (`noisetorch`) est
volontairement désactivée car elle requiert PulseAudio.

* **enable** `bool` Outils audio
* **enableTools** `bool` Outils / éditeurs audio (audacity, easyeffects)

```nix
darkone.home.audio = {
  enable = false;
  enableTools = false;
};
```

### &#x1F3E0; darkone.home.gnome

Réglages GNOME pour home-manager.

Masque les lanceurs : le simple `xterm`, les paramètres Qt5/Qt6 et le manuel
NixOS pour tous les profils, `scrcpy` et `scrcpy-console` s'ils sont installés,
Extensions pour les profils non techniques, et (`hideTechnicalIcons`)
Paramètres, Imprimantes et File Roller pour les profils débutant / enfant.
`keepKeyring` dispense l'utilisateur de la réinitialisation du trousseau de
connexion qui suit un changement de mot de passe administrateur (lu par le
module gnome de NixOS).

:::caution[Signets NFS]
Ne pas déclarer `gtk.gtk3.bookmarks` depuis ce module — tant que les partages
home NFS sont actifs, `home/profiles/minimal/nfs.nix` détient ce fichier et
l'écrase.
:::

* **enable** `bool` Activer les réglages gnome pour home manager
* **hideTechnicalIcons** `bool` Masquer certaines icônes pour débutants / enfants / bébés
* **keepKeyring** `bool` Conserver le trousseau de connexion quand l'administrateur change le mot de passe de session (trousseau avec un mot de passe propre)

```nix
darkone.home.gnome = {
  enable = false;
  hideTechnicalIcons = false;
  keepKeyring = false;
};
```

### &#x1F3E0; darkone.home.music

Applications graphiques de création musicale et sonore.

Classées par public : `enablePro` (ardour, reaper, renoise,
rosegarden), `enableCreator` (decibels, hydrogen), `enableScore`
(musescore, muse-sounds-manager), `enableFun` (mixxx, mousai),
`enableCli` (mpg123, cmus, lilypond), `enableEasy` (gnome-music vs.
audacious, GNOME uniquement), `enableMpd` (daemon MPD, ncmpcpp, mpd-mpris), et
`enableDev` (lilypond).

:::note[Bibliothèque musicale NFS-aware]
Quand l'hôte est un client NFS et que le réseau expose un service `nfs`
dans la même zone, MPD lit son répertoire musical depuis le montage NFS
(`/mnt/nfs/homes/$USER/Music`). Sinon il revient à la valeur locale
`srv-dirs.homes`, puis à `~/Music`.
:::

* **enablePro** `bool` Outils professionnels exigeants (rose, ardour...)
* **enableFun** `bool` Outils audio ludiques (mixxx...)
* **enableCli** `bool` Outils audio en ligne de commande (mpg123, cmus, moc...)
* **enableDev** `bool` Logiciels audio pour développeurs (lilypond...)
* **enableMpd** `bool` Daemon MPD et lecteurs (mpd, ncmpcpp...)
* **enableEasy** `bool` Outils simples plutôt qu'efficaces (gnome-music vs audacious...)
* **enableScore** `bool` Logiciels de notation (musescore...)
* **enableCreator** `bool` Outils de création pour débutants (lmms, hydrogen...)

```nix
darkone.home.music = {
  enable = false;
  enablePro = false;
  enableFun = false;
  enableCli = false;
  enableDev = false;
  enableMpd = false;
  enableEasy = false;
  enableScore = false;
```

### &#x1F3E0; darkone.home.office

Bureau de bureau : navigateurs, suite bureautique, communication, cloud et outils PDF.

Les paquets sont contrôlés par des drapeaux par public (`enableEssentials`,
`enableOffice`, `enableTools`, `enableCommunication`...). Sous-modules (`office/`) :

- `browsers.nix` : Firefox ESR (LibreWolf, Chromium) avec politiques partagées :
  page d'accueil et locale de la zone, protection contre le suivi, Bitwarden
  épinglé si le réseau fait tourner Vaultwarden.
- `matrix.nix` : dès que le réseau fait tourner Matrix, Element Desktop,
  pré-configuré (SSO Kanidm) ; Fractal avec `enableCommunication`.
- `nextcloud.nix` : client de bureau lié à l'instance du réseau, et
  `nextcloud-webdav-login` pour GNOME Online Accounts.
- `pandoc.nix` : `md2pdf` et les réglages par défaut de pandoc (`enablePandoc`).

* **enable** `bool` Paquets utiles par défaut
* **enableMore** `bool` Plus de paquets alternatifs
* **enableUnsafeFeatures** `bool` Fonctionnalités pour utilisateurs avancés non-enfants
* **enableUBlock** `bool` Activer le plugin ublock
* **enableTools** `bool` Petits outils (gnome) (iotas, dialect, etc.)
* **enableProductivity** `bool` Apps de productivité (obsidian, gestion du temps, projets, etc.)
* **enableCommunication** `bool` Outils de communication
* **enableOffice** `bool` Paquets bureautiques (libreoffice, hunspell, polices...)
* **enableFirefox** `bool` Activer firefox
* **enableLibreWolf** `bool` Activer LibreWolf (alternative à firefox)
* **enableChromium** `bool` Activer chromium
* **enableBrave** `bool` Activer Brave Browser
* **enableEmail** `bool` Paquets de gestion du courrier (thunderbird)
* **enableSecurity** `bool` Outils de sécurité (keepass)
* **enableCalendarContacts** `bool` Calendrier, contacts, tâches et apps associées
* **enablePandoc** `bool` Chaîne d'outils Markdown vers PDF : pandoc, typst, polices Gentium et DejaVu,
  et la commande `md2pdf` (corps Gentium, A4, la langue de la zone).

  ```sh
  md2pdf notes.md              # A4, 10pt -&gt; notes.pdf
  md2pdf --big notes.md        # A4, 12pt
  md2pdf --tablet notes.md     # A6, 9pt (11pt avec --big), zoomé sur une tablette
  md2pdf -e context notes.md   # moteur ConTeXt (enablePandocContext)
  ```

  Le moteur est typst. Il rend le TeX brut courant dans les notes (`\pagebreak`,
  `\placecontent`, `\centerline`...) et signale tout autre élément. Les colonnes
  des tableaux s'ajustent à leur contenu, sauf si les tirets de séparation
  diffèrent en longueur (`|--|--------|`) : les largeurs les suivent alors.
  Un simple `pandoc notes.md -o notes.pdf` utilise le même moteur, la même
  langue et les mêmes polices.
  Sous GNOME, les trois dispositions sont aussi proposées au clic droit dans
  Nautilus (menu Scripts).
* **enablePandocContext** `bool` ConTeXt comme moteur PDF alternatif, `md2pdf -e context` (~900 MiO, requiert enablePandoc)
* **pandocAuthor** `nullOr str` Créateur écrit dans les PDF par `md2pdf`. `null` prend le nom complet du compte.
* **enableEssentials** `bool` Outils essentiels
* **hunspellLang** `str` [Dictionnaire Hunspell](https://mynixos.com/nixpkgs/packages/hunspellDicts)
* **enableElementAutoStart** `bool` Démarrage automatique d'Element Desktop (masqué) à la connexion quand le réseau fait tourner Matrix
* **enableFractalAutoStart** `bool` Démarrage automatique de Fractal à la connexion, avec `enableCommunication` (opt-in : pas de mode arrière-plan, sa fenêtre s'ouvre)
* **nextcloud.enable** `bool` Installer le client de bureau Nextcloud, pré-lié à l'instance du réseau
* **nextcloud.server** `nullOr str` Instance Nextcloud à laquelle le client se lie. `null` choisit celle déclarée
  sur le réseau (cette zone d'abord). Définissez-la pour viser une instance
  locale ou externe à la place.
* **nextcloud.enableAutoStart** `bool` Démarrer le client Nextcloud en arrière-plan à la connexion
* **nextcloud.enableWebdav** `bool` Fournir `nextcloud-webdav-login`, un assistant one-shot qui authentifie
  via le navigateur (SSO Kanidm) et enregistre le résultat comme compte GNOME
  Online : fichiers via WebDAV dans le gestionnaire de fichiers, plus
  calendrier et contacts dans Evolution. Nécessaire car Nextcloud refuse de
  créer un mot de passe d'application depuis son interface web pour un
  utilisateur OIDC.

  L'assistant affiche aussi le mot de passe d'application, si bien que tout
  autre client WebDAV peut être pointé vers le même compte.

  :::note[GNOME uniquement]
  Le compte est écrit là où GNOME Online Accounts le lit, ce que
  `darkone.graphic.gnome` active dès que le réseau porte un cloud.
  Sur un autre bureau, le mot de passe affiché reste utilisable.
  :::

  Ignoré quand `darkone.home.office.nextcloud.enable` est désactivé.
* **nextcloud.syncDir** `nullOr str` Dossier local pré-rempli dans l'assistant de configuration, relatif à `$HOME`.

  :::caution[Pas de synchro par défaut]
  Laissé `null` volontairement. L'assistant s'arrête alors sur sa page de
  dossier et l'utilisateur décide quoi synchroniser, le cas échéant. Le
  définir saute cette page.
  :::
* **shared** `raw` Valeurs du bureau partagées avec les sous-modules `office/`.

```nix
darkone.home.office = {
  enable = false;
  enableMore = false;
  enableUnsafeFeatures = false;
  enableUBlock = false;
  enableTools = false;
  enableProductivity = false;
  enableCommunication = false;
  enableOffice = false;
  enableFirefox = false;
  enableLibreWolf = false;
  enableChromium = false;
  enableBrave = false;
  enableEmail = false;
  enableSecurity = false;
  enableCalendarContacts = false;
  enablePandoc = false;
  enablePandocContext = false;
  pandocAuthor = "Jane Doe";
  enableEssentials = true;
  hunspellLang = "en-us";
  enableElementAutoStart = true;

  nextcloud.enable = detectedNextcloud != null;

      };
```

### &#x1F3E0; darkone.home.umi

Saisie multimodale unifiée (UMI)

Écran tactile + voix + regard (démarrage automatique de Talon + Onboard).

:::note[La session dépend de l'hôte]
- **Hôte `darkone.host.umi`** : session Cinnamon X11 (udev, uinput, Talon
  fournis par l'hôte). Talon et un clavier Onboard ancré (prédiction de
  mots, modificateurs collants) démarrent avec la session, le clavier
  masqué tant qu'on ne le demande pas. Panneau, icônes et texte agrandis
  pour les cibles de regard (`panelHeight`, `textScaling`). Panneau DNF
  (`enablePanel`) : lanceurs | fenêtres ouvertes, puis types de clic au
  survol, zone de pause, commutateur de regard (applet `umi-mouse`),
  menu d'accessibilité, bascule Onboard. Les favoris du menu
  (`menuFavorites`) s'ouvrent avec le calibrage du tracker oculaire.
- **Tout autre hôte** : GNOME Wayland avec son accessibilité native :
  clavier à l'écran, pointeur et texte agrandis. Talon et Onboard, en
  X11 uniquement, restent désactivés.

Clic par pause : à activer (`enableDwell`) sous GNOME. Sous Cinnamon, un
script utilisateur Talon le fait suivre le tracker oculaire, avec contrôle
par regard (`enableTrackerAuto`). Talon 0.4 et 1.0 au même titre&nbsp;; le
mode « Always On » de 1.0 est désactivé, le tracker s'éteint avec le
contrôle par regard.
:::

:::note[Grille d'applications (hôte UMI)]
`enableRofiMenu` : le premier lanceur du panneau ouvre une grille rofi
plein écran, des pages de tuiles `rofiGridResolution` parcourues par des
boutons en bordure, un clic lance, les panneaux de paramètres exclus.
`hiddenApps` masque des entrées de la grille comme du menu Cinnamon. rofi
attrape le pointeur : panneau hors de portée.
:::

:::note[Pointage au seul regard (Talon 1.0)]
Les filtres de Talon figent le curseur ~2 mm avant le regard : le script
les relève (`gazeFilterSpeed`, `cursorFilterSpeed`, mesurés sur un
Tobii 5). Les modes du menu Eye Tracking sont déclarés
(`enableGazeControl`, `enableHeadControl`, `enableHeadJump`,
`enableMouseJump`, `enableGazeFocus`) et réappliqués à chaque démarrage
de Talon : regard seul par défaut, une tête instable entraîne le curseur.
:::

:::tip[Le regard place, la tête affine]
Avec `enableHeadControl`, `headSpeed` sous 1 amortit les mouvements de
tête amples (`head_bezier.vmax` mis à l'échelle, levier à valider sur un
Tobii 5). Réglage en direct depuis le REPL de Talon, perdu au
redémarrage : `actions.user.umi_head_speed(0.3)`,
`actions.user.umi_filter_speed(2, 4)`, `print(actions.user.umi_tuning())`.
:::

:::tip[Scripts communautaires]
Renseigner `communityScripts` avec un arbre github:talonhub/community
récupéré donne un contrôle complet souris-par-voix et souris-par-regard
(zoom mouse, pop click) de façon déclarative.
:::

:::note[Deux schémas]
Les paramètres vont dans les deux familles : org/cinnamon/* pour la
session de l'hôte UMI, org/gnome/* pour les sessions GNOME ailleurs. Sous
Cinnamon, csd réplique les touches souris d'accessibilité entre les deux
familles, dans les deux sens.
Exception : les touches verrouillées par le module gnome de DNF ne sont
jamais écrites ici, une écriture sur une touche verrouillée annule tout le
`dconf load` de home-manager.
Le verrouillage de l'écran reste activé côté GNOME (verrouillé par le
module gnome de DNF)&nbsp;; `idle-delay = 0` évite de le déclencher, et la
session Cinnamon a sa propre verrouillage entièrement désactivé.
:::

:::caution[Anneau de clés de connexion : utilisateur à connexion automatique seulement, deux modes décidés par l'hôte]
Une session à connexion automatique ne tape aucun mot de passe, PAM n'a
donc rien à transmettre à gnome-keyring et chaque application utilisant des
secrets affiche une invite gcr à laquelle l'utilisateur UMI ne peut
répondre. Une connexion par mot de passe déverrouille l'anneau de clés
comme d'habitude et reste inchangée. Pour l'utilisateur à connexion
automatique, le correctif dépend de l'hôte :

- **Hôte non chiffré** : l'anneau de clés de connexion est initialisé avec
  un mot de passe vide, que gnome-keyring stocke en clair et qui le
  déverrouille de lui-même (il essaie un mot de passe vide avant de
  demander). Tout anneau de clés existant protégé par mot de passe est
  supprimé — sa phrase secrète est intapable ici, elle ne produirait donc
  que l'invite pour toujours. La connexion automatique accorde déjà toute
  la session à qui démarre la machine, cela ne coûte donc aucune
  confidentialité réelle.
- **Hôte chiffré** (`darkone.system.luks.volumes` non vide) : rien n'est
  initialisé. La phrase secrète tapée au démarrage est mise en cache dans
  l'anneau de clés du noyau et transmise à gnome-keyring par `pam_gdm`,
  l'anneau reste donc chiffré avec elle. C'est le seul mode qui protège
  les secrets au repos.

Réserve, hôtes chiffrés seulement : la rotation de la phrase secrète LUKS
(valeur sops modifiée, `luks-passphrase-sync`) laisse l'anneau sur
l'ancienne — GNOME annonce alors « The password you use to log in to your
computer no longer matches that of your login keyring ». Supprimer
`~/.local/share/keyrings/login.keyring` et se reconnecter.
:::

* **enable** `bool` Configuration de la saisie multimodale UMI (Talon + Onboard)
* **enableTalonAutostart** `bool` Démarrer Talon à la connexion de la session (talon doit être dans le PATH).
* **communityScripts** `nullOr package` arbre talonhub/community déployé vers ~/.talon/user/community.
* **enableDwell** `bool` clic par pause : cliquer en laissant le pointeur au repos. Désactivé par défaut —
  utilisable uniquement avec un tracker oculaire, et avec une souris il se
  déclenche sur ce où le pointeur était posé (le menu d'accessibilité qui
  bascule le zoom ou le clavier à l'écran, en général)
* **dwellTime** `float` Délai du clic par pause en secondes.
* **enableTrackerAuto** `bool` Tracker oculaire branché : contrôle souris par regard Talon et clic au
  survol activés ; débranché : clic au survol désactivé (session
  Cinnamon). Prend le dessus sur `enableDwell` sous Cinnamon.
* **gazeFilterSpeed** `nullOr numbers.positive` Coefficient du filtre de regard par œil du Control Mouse de Talon, avec
  `enableTrackerAuto` : plus haut réagit plus vite et lisse moins. La
  valeur propre de Talon (1.0) fige le curseur avant le regard ; `null`
  la conserve.
* **cursorFilterSpeed** `nullOr numbers.positive` Coefficient du filtre de curseur du Control Mouse de Talon, avec
  `enableTrackerAuto` : plus haut réagit plus vite, dépasse plus.
  `null` conserve la valeur propre de Talon (2.0).
* **headSpeed** `nullOr numbers.positive` Sensibilité du Head Control de Talon, avec `enableTrackerAuto` et
  `enableHeadControl` : sous 1 la tête déplace moins le curseur (mouvements
  amples, mal contrôlés). `null` conserve la valeur propre de Talon (1).
* **enableGazeControl** `bool` Gaze Control de Talon, avec `enableTrackerAuto` : le curseur suit le regard.
* **enableHeadControl** `bool` Head Control de Talon, avec `enableTrackerAuto` : les mouvements de tête
  déplacent aussi le curseur. Désactivé par défaut, une tête instable
  entraîne le curseur hors du regard
* **enableHeadJump** `bool` Head Jump de Talon, avec `enableTrackerAuto` : un mouvement de tête amène
  le curseur au regard
* **enableMouseJump** `bool` Mouse Jump de Talon, avec `enableTrackerAuto` : déplacer une vraie souris
  vers le regard y amène le curseur. Désactivé par défaut, il agite le
  pointeur d'un assistant
* **enableGazeFocus** `bool` Gaze Focus de Talon (expérimental), avec `enableTrackerAuto` : la fenêtre
  regardée prend le focus
* **panelHeight** `ints.between 40 96` Hauteur du panneau Cinnamon en pixels, ses icônes suivent (cibles de regard).
* **textScaling** `float` Facteur d'échelle du texte de la session Cinnamon (les boutons grossissent avec leurs libellés).
* **enablePanel** `bool` Panneau Cinnamon géré par DNF : lanceurs et fenêtres ouverts séparés,
  commandes de clic au survol (types de clic, zone de pause), menu
  d'accessibilité, bascule du clavier. Réécrit à chaque activation.
* **panelLaunchers** `listOf str` Lanceurs du panneau (ids de fichiers desktop), avec `enablePanel`.
* **menuFavorites** `listOf str` Favoris du menu Cinnamon (ids de fichiers desktop), réécrits à chaque
  activation. `dnf-umi-calibrate.desktop`, avec `enableTrackerAuto`,
  lance le calibrage du tracker oculaire.
* **enableRofiMenu** `bool` Grille d'applications plein écran (rofi), hôte UMI seulement : pages de
  grandes tuiles parcourues par des boutons en bordure, un clic lance,
  les panneaux de paramètres exclus. Ouverte par le premier lanceur du
  panneau (avec `enablePanel`).
* **rofiGridResolution** `submodule` Page de la grille d'applications, en tuiles, avec `enableRofiMenu`. La
  par défaut 6 × 4 tient des icônes de 96 px sur un écran 1600×900&nbsp;;
  moins de tuiles les élargit.
  * **columns** `ints.between 1 12` Tuiles par rangée.
  * **rows** `ints.between 1 8` Rangées de tuiles par page.
* **hiddenApps** `listOf str` Applications masquées de la grille et du menu Cinnamon (ids de fichiers
  desktop), hôte UMI seulement. Le lancement par id et les associations
  de fichiers fonctionnent toujours.

```nix
darkone.home.umi = {
  enable = false;
  enableTalonAutostart = true;
  communityScripts = null;
  enableDwell = false;
  dwellTime = 1.2;
  enableTrackerAuto = true;
  gazeFilterSpeed = 2.0;
  cursorFilterSpeed = 4.0;
  headSpeed = 0.3;
  enableGazeControl = true;
  enableHeadControl = false;
  enableHeadJump = false;
  enableMouseJump = false;
  enableGazeFocus = false;
  panelHeight = 64;
  textScaling = 1.5;
  enablePanel = true;
  panelLaunchers = [ ];
  menuFavorites = [ ];
  enableRofiMenu = true;
  rofiGridResolution.columns = 6;
  rofiGridResolution.rows = 4;
  hiddenApps = [ ];
};
```

### &#x1F3E0; darkone.home.video

Outils et applications vidéo.

Installe toujours le lecteur par défaut (`celluloid`, interface GTK4/libadwaita
sur mpv) et contrôle le reste par public : `enableTools` (ffmpeg, mlt, vlc,
video-trimmer, parabolic), `enableEditing` (kdenlive, shotcut),
`enableCreator` (OBS Studio avec `obs-backgroundremoval`, `obs-vkcapture`,
etc.), `enableUnfree` (davinci-resolve) et `enableAlternative` (mpv).

:::caution[Pas GNOME Showtime]
Showtime 50 plante en interbloqué sur certains fichiers — `get_state(CLOCK_TIME_NONE)` sur le
fil principal, [GNOME/showtime#299](https://gitlab.gnome.org/GNOME/showtime/-/work_items/299).
Le processus bloqué conserve le nom D-Bus `org.gnome.Showtime`, si bien que
chaque lancement ultérieur est activé sur lui et ne fait silencieusement rien :
ni fenêtre, ni journal.
Non corrigé en amont en 50.0.
:::

* **enable** `bool` Module home de création et d'outils vidéo
* **enableTools** `bool` Outils vidéo pour professionnels
* **enableEditing** `bool` Outils de montage vidéo (kdenlive...)
* **enableCreator** `bool` Outils de création vidéo (obs...)
* **enableUnfree** `bool` Apps vidéo non libres (davinci...)
* **enableAlternative** `bool` Apps vidéo alternatives (mpv...)

```nix
darkone.home.video = {
  enable = false;
  enableTools = false;
  enableEditing = false;
  enableCreator = false;
  enableUnfree = false;
  enableAlternative = false;
};
```
