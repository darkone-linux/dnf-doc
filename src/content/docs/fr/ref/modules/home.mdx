### &#x1F3E0; darkone.home.advanced
Profil maison pour les utilisateurs avancés (informaticiens, développeurs, administrateurs).

:::note[Clés SSH depuis Vaultwarden]
`enableVaultwardenSsh` transforme `rbw` en agent SSH : les clés privées restent
dans le coffre de l'utilisateur (chiffré de bout en bout), jamais en clair sur le
disque ni dans sops. L'utilisateur lance `rbw unlock` une fois par session.
:::

:::note[Dossier Réseau local]
Un nix-admin sur l'hôte d'administration dispose d'un dossier « Réseau local »
dans la grille d'applications (`advanced/network-folder.nix`) : DNF Doc,
Onboarding (la page d'accueil) et Sources réseau (un terminal dans
`/etc/nixos`). Ajouté une fois par utilisateur, à la connexion.
:::

* **enable** `bool` Activer les fonctionnalités pour utilisateurs avancés
* **enableTools** `bool` Divers outils pour utilisateurs avancés
* **enablePhoneTools** `bool` Outils pour smartphone (scrcpy)
* **enableAdmin** `bool` Activer les fonctionnalités administrateur (réseau, outils système)
* **enableNixAdmin** `bool` Activer les fonctionnalités d'administration Nix
* **enableDnfDeveloper** `bool` Activer tous les outils pour le développeur DNF Codev
* **enableDeveloper** `bool` Activer les outils pour développeur
* **enableVscode** `bool` VS Code. Opt-in : ~0,3 Gio à télécharger, Zed est l'éditeur par défaut
* **enableSlidev** `bool` Presentations Slidev (`slidev-cli`, plus son extension VS Code quand
  `enableVscode`). Opt-in : ~0,4 Gio à télécharger
* **enableEssentials** `bool` Outils fréquemment utilisés
* **enableVaultwardenSsh** `bool` Agent SSH reposant sur le coffre Vaultwarden de l'utilisateur (rbw). Ne pas activer sur
  un hôte atteint avec `ssh -A` : l'agent local masquerait celui qui est transféré

```nix
darkone.home.advanced = {
  enable = false;
  enableTools = false;
  enablePhoneTools = false;
  enableAdmin = false;
  enableNixAdmin = false;
  enableDnfDeveloper = false;
  enableDeveloper = true;
  enableVscode = false;
  enableSlidev = false;
  enableEssentials = true;
  enableVaultwardenSsh = false;
};
```

### &#x1F3E0; darkone.home.ai-space

Outils d'agent d'un espace IA dans le foyer d'un membre&nbsp;: Claude Code, Codex, OpenCode, MCP, skills.

Tout vient de l'espace (`darkone.host.ai-space` de l'hôte), donc OpenClaw et chaque membre partagent les mêmes serveurs MCP et skills. Activé par défaut dans le foyer `space-member`&nbsp;; désactivé sur tout autre hôte.

- MCP&nbsp;: HM `programs.mcp`, intégré à Claude Code, Codex et OpenCode&nbsp;;
- skills&nbsp;: `~/.claude/skills`, `~/.codex/skills`, `~/.config/opencode/skills`&nbsp;;
- connexions&nbsp;: une fois par membre, `claude` (`/login`), `codex login --device-auth`, `opencode auth login`&nbsp;;
- `~/projects`&nbsp;: les projets partagés de l'espace (`projectsDir`).

:::note[Par membre, par espace]
`usr/users/<login>/spaces/<host>.nix` ajoute ou remplace, par exemple un serveur MCP personnel&nbsp;: `programs.mcp.servers.<name> = { ... };`.
:::

* **enable** `bool` Outils d'agent de l'espace IA (Claude Code, Codex, OpenCode, MCP, skills)

```nix
darkone.home.ai-space.enable = false;
```

### &#x1F3E0; darkone.home.ai

Outils de codage IA et utilitaires associés.

:::note[Drapeaux]
- `darkone.home.ai.enable` : paquets utilitaires (aichat, llm, fabric-ai, gh,
  lazygit, direnv, outils Rust et qualité de code) et les drapeaux d'agent ci-dessous.
- `darkone.home.ai.enable{Claude,OpenCode,Codex,Antigravity,Aider,Goose}` :
  un agent de codage IA chacun.
- `darkone.home.ai.preferLocal` : OpenCode utilise par défaut le modèle ollama
  local sur un hôte `darkone.service.ai`.
:::

:::tip[Câblage par hôte]
Sur un hôte ollama local (`darkone.service.ai`) : `gollama` et la CLI
`ollama`, et Aider revient au modèle local quand Claude est désactivé.

La CLI GitHub (`gh`) et la CLI Copilot (`copilot`) sont installées. Claude Code
applique une matrice de permissions autoriser/demander/refuser et un hook de
gouvernance RTK sur les appels Bash.
:::

:::caution[settings.json modifiable]
Claude Code et Antigravity CLI réécrivent leur propre `settings.json` : un
lien symbolique en lecture seule les casse, et fait échouer le prochain switch
sur le `.bkp`. Le socle Nix est fusionné par jq dans un fichier MODIFIABLE à
chaque switch à la place ; les clés d'exécution (plugins, espaces de travail
de confiance) sont préservées.
:::

* **enable** `bool` Activer les outils IA et les utilitaires associés
* **enableClaude** `bool` CLI Claude Code
* **enableOpenCode** `bool` Agent IA terminal OpenCode
* **enableCodex** `bool` CLI OpenAI Codex
* **enableAntigravity** `bool` CLI Google Antigravity
* **enableAider** `bool` Programmation en binôme IA avec Aider
* **enableGoose** `bool` Agent de codage IA Goose (Block Inc.)
* **preferLocal** `bool` Préférer les modèles locaux plutôt que cloud

```nix
darkone.home.ai = {
  enable = false;
  enableClaude = false;
  enableOpenCode = false;
  enableCodex = false;
  enableAntigravity = false;
  enableAider = false;
  enableGoose = false;
  preferLocal = false;
};
```

```nix

  enable = false;
  enableTools = false;
};
```

### &#x1F3E0; darkone.home.gnome

Réglages Gnome pour home-manager.

Masque des lanceurs : le `xterm` nu, les réglages Qt5/Qt6 et le manuel NixOS
pour chaque profil, `scrcpy` et `scrcpy-console` s'ils sont installés,
Extensions pour les profils non techniques, et (`hideTechnicalIcons`)
Paramètres, Imprimantes et File Roller pour les profils débutant / enfant.
`hiddenApps` (par défaut : vim, btop, htop) en masque davantage, les entrées
restant lançables par id (`gnome/hidden-apps.nix`, partagé avec le module UMI).
`keepKeyring` dispense l'utilisateur de la réinitialisation du trousseau de
connexion suite au changement du mot de passe admin (lu par le module gnome
de NixOS).

:::caution[Signets NFS]
Ne pas déclarer `gtk.gtk3.bookmarks` depuis ce module — tant que les partages
home NFS sont actifs, `home/profiles/minimal/nfs.nix` détient ce fichier et
l'écrase.
:::

* **enable** `bool` Activer les réglages gnome pour home manager
* **hideTechnicalIcons** `bool` Masquer certaines icônes pour les débutants / enfants / bébés
* **keepKeyring** `bool` Conserver le trousseau de connexion quand l'admin change le mot de passe de session (trousseau avec un mot de passe propre)
* **hiddenApps** `listOf str` Entrées desktop masquées de la grille d'applications, toujours lançables par id

```nix
darkone.home.gnome = {
  enable = false;
  hideTechnicalIcons = false;
  keepKeyring = false;
  hiddenApps = [ ];
};
```

### &#x1F3E0; darkone.home.music

Applications graphiques de création musicale et sonore.

Classées par public : `enablePro` (ardour, reaper, renoise,
rosegarden), `enableCreator` (decibels, hydrogen), `enableScore`
(musescore, muse-sounds-manager), `enableFun` (mixxx, mousai),
`enableCli` (mpg123, cmus, lilypond), `enableEasy` (gnome-music vs.
audacious, GNOME uniquement), `enableMpd` (daemon MPD, ncmpcpp, mpd-mpris), et
`enableDev` (lilypond).

dans la même zone, MPD lit son répertoire musical depuis le montage NFS
(`/mnt/nfs/homes/$USER/Music`). Sinon il revient à la valeur locale
`srv-dirs.homes`, puis à `~/Music`.

* **enablePro** `bool` Outils professionnels exigeants (rose, ardour...)
* **enableFun** `bool` Outils audio ludiques (mixxx...)
* **enableCli** `bool` Outils audio en ligne de commande (mpg123, cmus, moc...)
* **enableDev** `bool` Logiciels audio pour développeurs (lilypond...)
* **enableMpd** `bool` Daemon MPD et lecteurs (mpd, ncmpcpp...)
* **enableEasy** `bool` Outils simples plutôt qu'efficaces (gnome-music vs audacious...)
* **enableScore** `bool` Logiciels de notation (musescore...)
* **enableCreator** `bool` Outils de création pour débutants (lmms, hydrogen...)

```nix
darkone.home.music = {
  enable = false;
```

### &#x1F3E0; darkone.home.office

Bureau de travail : navigateurs, suite bureautique, communication, cloud et outils PDF.

Les paquets sont filtrés selon le public (`enableEssentials`, `enableOffice`,
`enableTools`, `enableCommunication`...). Sous-modules (`office/`) :

- `browsers.nix` : Firefox ESR (LibreWolf, Chromium) avec des politiques partagées :
  page d'accueil et locale de la zone, protection contre le suivi, Bitwarden épinglé lorsque
  le réseau exécute Vaultwarden.
- `cartable-fantastique.nix` : barre d'outils Cartable Fantastique dans LibreOffice
  (`cartableFantastique`, par défaut pour le profil `child`).
- `matrix.nix` : Element Desktop dès que le réseau exécute Matrix,
  préconfiguré (SSO Kanidm) ; Fractal avec `enableCommunication`.
- `nextcloud.nix` : client de bureau lié à l'instance du réseau, et
  `nextcloud-webdav-login` pour les Comptes en ligne GNOME.
- `pandoc.nix` : `md2pdf` et les paramètres par défaut de pandoc (`enablePandoc`).

* **enable** `bool` Paquets utiles par défaut
* **enableMore** `bool` Plus de paquets alternatifs
* **enableUnsafeFeatures** `bool` Fonctionnalités pour utilisateurs avancés non-enfants
* **enableUBlock** `bool` Activer l'extension uBlock
* **enableTools** `bool` Petits outils (GNOME) (iotas, dialect, etc.)
* **enableProductivity** `bool` Applications de productivité (obsidian, gestion du temps, projets, etc.)
* **enableCommunication** `bool` Outils de communication
* **enableOffice** `bool` Paquets bureautiques (libreoffice, hunspell, polices...)
* **enableFirefox** `bool` Activer Firefox
* **enableLibreWolf** `bool` Activer LibreWolf (alternative à Firefox)
* **enableChromium** `bool` Activer Chromium
* **enableBrave** `bool` Activer Brave Browser
* **enableEmail** `bool` Paquets de gestion de courriel (thunderbird)
* **enableSecurity** `bool` Outils de sécurité (keepass)
* **enableCalendarContacts** `bool` Calendrier, contacts, tâches et applications associées
* **enablePandoc** `bool` Chaîne d'outils Markdown vers PDF : pandoc, typst, polices Gentium et DejaVu,
  et la commande `md2pdf` (corps Gentium, A4, langue de la zone).

  ```sh
  md2pdf notes.md              # A4, 10pt -&gt; notes.pdf
  md2pdf --big notes.md        # A4, 12pt
  md2pdf --tablet notes.md     # A6, 9pt (11pt avec --big), agrandi pour tablette
  md2pdf -e context notes.md   # Moteur ConTeXt (enablePandocContext)
  ```

  Le moteur est typst. Il rend le code TeX brut habituel dans les notes (`\pagebreak`,
  `\placecontent`, `\centerline`...) et signale tout autre code. Les colonnes de tableau
  s'adaptent à leur contenu, sauf si les tirets des séparateurs diffèrent en
  longueur (`|--|--------|`) : les largeurs suivent alors ces tirets. Un simple
  `pandoc notes.md -o notes.pdf` utilise le même moteur, la même langue et les mêmes polices.
  Sous GNOME, les trois mises en page sont également proposées par clic droit dans
  Nautilus (menu Scripts).
* **enablePandocContext** `bool` ConTeXt comme moteur PDF alternatif, `md2pdf -e context` (~900 MiB, nécessite enablePandoc)
* **pandocAuthor** `nullOr str` Créateur inscrit dans les PDFs générés par `md2pdf`. `null` utilise le nom complet du compte.
* **enableEssentials** `bool` Outils essentiels
* **hunspellLang** `str` [Dictionnaire Hunspell](https://mynixos.com/nixpkgs/packages/hunspellDicts)
* **cartableFantastique** `nullOr ( enum [ "primaire" "college" "adaptateur" ] )` Édition de la barre d'outils [Cartable Fantastique](https://www.cartablefantastique.fr/outils-pour-compenser/le-plug-in-libre-office/)
  installée dans LibreOffice, à destination des élèves dyspraxiques ou atteints d'autres troubles DYS.
  `null` n'installe rien.

  - `primaire` : barres Lire, Écrire, Mathématiques et Tableau.
  - `college` : ajoute les langues, la chimie, l'électricité et l'éditeur d'équations.
  - `adaptateur` : ajoute des outils pour l'adulte adaptant le matériel scolaire.

  Installée par compte, dans son profil LibreOffice, lors de l'activation de Home Manager.
  Nécessite `enableOffice`. La synthèse vocale passe par `spd-say` (speech-dispatcher, activé par défaut
  sur les bureaux NixOS).

  :::caution[Pas de suppression automatique]
  En repassant à `null`, l'extension reste installée : supprimez-la depuis *Outils → Gestionnaire d'extensions*.
  :::
* **enableElementAutoStart** `bool` Démarrage automatique d'Element Desktop (masqué) à la connexion lorsque le réseau exécute Matrix
* **enableFractalAutoStart** `bool` Démarrage automatique de Fractal à la connexion, avec `enableCommunication` (opt-in : pas de mode arrière-plan, sa fenêtre s'ouvre)
* **nextcloud.enable** `bool` Installer le client de bureau Nextcloud, prélié à l'instance du réseau
* **nextcloud.server** `nullOr str` Instance Nextcloud à laquelle le client se lie. `null` sélectionne celle déclarée
  sur le réseau (cette zone en priorité). Définissez-la pour cibler une instance locale ou externe.
* **nextcloud.enableAutoStart** `bool` Démarrer le client Nextcloud en arrière-plan à la connexion
* **nextcloud.enableWebdav** `bool` Fournir `nextcloud-webdav-login`, un assistant ponctuel qui s'authentifie
  via le navigateur (SSO Kanidm) et enregistre le résultat comme un Compte en ligne GNOME :
  fichiers via WebDAV dans le gestionnaire de fichiers, ainsi que calendrier
  et contacts dans Evolution. Nécessaire car Nextcloud refuse de créer
  un mot de passe d'application depuis son interface web pour un utilisateur OIDC.

  L'assistant affiche également le mot de passe d'application, afin que tout autre client WebDAV
  puisse l'utiliser avec ce compte.

  :::note[Uniquement GNOME]
  Le compte est écrit à l'emplacement lu par les Comptes en ligne GNOME, que
  `darkone.graphic.gnome` active de lui-même dès que le réseau
  propose un cloud. Sur un autre bureau, le mot de passe affiché reste utilisable.

### &#x1F3E0; darkone.home.umi

Entrée multimodale unifiée (UMI)

Écran tactile + voix + regard (autostart de Talon + Onboard).

:::note[La session dépend de l'hôte]
- **Hôte `darkone.host.umi`**&nbsp;: session Cinnamon X11 (udev, uinput, Talon fournis par l'hôte). Talon et un clavier Onboard ancré (prédiction de mots, modificateurs collants) démarrent avec la session, le clavier masqué jusqu'à demande. Panneau, icônes et texte agrandis pour les cibles du regard (`panelHeight`, `textScaling`). Panneau DNF (`enablePanel`)&nbsp;: lanceurs | fenêtres ouvertes, puis types de clic au survol, zone de pause, bascule du regard (applet `umi-mouse`), menu d'accessibilité, bascule Onboard. Les favoris du menu (`menuFavorites`) s'ouvrent avec la calibration de l'eye tracker. Les fenêtres d'application s'ouvrent maximisées, panneau à portée (`enableMaximize`).
- **Tout autre hôte**&nbsp;: GNOME Wayland avec son accessibilité native&nbsp;: clavier à l'écran, grand pointeur et grand texte. Talon et Onboard, réservés à X11, restent désactivés.

Clic par maintien&nbsp;: opt-in (`enableDwell`) sous GNOME. Dans Cinnamon, un script utilisateur Talon le fait suivre l'eye tracker, avec contrôle du regard (`enableTrackerAuto`). Talon 0.4 comme 1.0&nbsp;; l'« Always On » de la 1.0 est désactivé, le tracker s'éteint avec le contrôle du regard.

Reconnaissance vocale&nbsp;: en veille à chaque démarrage de Talon sauf avec `enableSpeech`.
:::

:::note[Grille d'applications (hôte UMI)]
`enableRofiMenu`&nbsp;: le premier lanceur du panneau ouvre une grille rofi plein écran, des pages de `rofiGridResolution` tuiles tournées par des boutons en bordure haute, un clic lance, les panneaux de réglages exclus. `hiddenApps` masque des entrées de la grille comme du menu Cinnamon. rofi accapare le pointeur&nbsp;: panneau hors de portée.
:::

:::note[SuperTuxKart à la souris seule (hôte UMI)]
`enableStkWithMouse`&nbsp;: le lanceur du jeu exécute `dnf-stk-mouse`, qui transforme chaque souris physique en touches par défaut de STK tant que la fenêtre du jeu a le focus. Stick avant/arrière&nbsp;: accélérer/freiner, latéral&nbsp;: diriger&nbsp;; clic gauche&nbsp;: dérapage, double clic&nbsp;: tir, clic droit&nbsp;: nitro. Pointeur intact (menus).
:::

:::note[Le regard place, la tête affine (Talon 1.0)]
Valeurs par défaut mesurées sur un Tobii 5&nbsp;: filtre de regard de Talon (`gazeFilterSpeed`), un filtre de curseur plus rapide (`cursorFilterSpeed`), contrôle de la tête activé avec une tête sensible (`headSpeed` 5, `head_bezier.vmax` mis à l'échelle). Les modes du menu Eye Tracking sont déclarés (`enableGazeControl`, `enableHeadControl`, `enableHeadJump`, `enableMouseJump`, `enableGazeFocus`) et réappliqués à chaque démarrage de Talon.
:::

:::tip[Réglage en direct]
Depuis le REPL de Talon, perdu au redémarrage&nbsp;: `actions.user.umi_head_speed(5)`, `actions.user.umi_filter_speed(1, 4)`, `print(actions.user.umi_tuning())`.
:::

:::tip[Scripts communautaires]
Définir `communityScripts` sur une arborescence github:talonhub/community récupérée pour obtenir, de façon déclarative, un contrôle complet de la souris à la voix et au regard (zoom mouse, pop click).
:::

:::note[Double schéma]
Les réglages vont vers les deux familles&nbsp;: org/cinnamon/* pour la session de l'hôte UMI, org/gnome/* pour les sessions GNOME ailleurs. Dans Cinnamon, csd recopie les clés souris d'accessibilité entre les deux familles, dans les deux sens.
Exception&nbsp;: les clés verrouillées par le module gnome de DNF ne sont jamais écrites ici&nbsp;; une écriture sur une clé verrouillée annule tout le `dconf load` de home-manager.
Le verrouillage d'écran reste activé côté GNOME (verrouillé par le module gnome de DNF)&nbsp;; `idle-delay = 0` évite de le déclencher, et la session Cinnamon a son propre verrou entièrement désactivé.
:::

:::caution[Trousseau de connexion de l'utilisateur autologin&nbsp;: sans mot de passe, sur chaque hôte]
Une session autologin ne saisit aucun mot de passe&nbsp;: un trousseau scellé par un mot de passe déclenche une invite gcr à laquelle l'utilisateur UMI ne peut répondre. Son trousseau de connexion est amorcé avec un mot de passe vide (ini en clair, déverrouillé sans invite)&nbsp;; un trousseau scellé est supprimé à chaque activation, `user.keystore` inclus, et ses secrets sont perdus.

- Au repos, LUKS le protège&nbsp;; l'autologin confie déjà la session à quiconque démarre la machine.
- L'hôte UMI tient tous les mots de passe à l'écart de gnome-keyring pour cet utilisateur&nbsp;: un trousseau en clair déverrouillé avec un mot de passe est rechiffré avec celui-ci à la prochaine écriture (`pam_gdm` et la phrase de passe de démarrage inclus).
- Les autres utilisateurs, et toute connexion par mot de passe ailleurs&nbsp;: inchangés.
:::

* **enable** `bool` Configuration de l'entrée multimodale UMI (Talon + Onboard)
* **enableTalonAutostart** `bool` Démarrer Talon à la connexion à la session, une fois la zone de notification du panneau prête (talon doit être dans le PATH).
* **communityScripts** `nullOr package` Arborescence talonhub/community déployée dans ~/.talon/user/community.
* **enableSpeech** `bool` Reconnaissance vocale de Talon au démarrage. Désactivée par défaut&nbsp;: mise en veille à chaque démarrage de Talon, des mots parasites ne doivent pas déclencher de commandes
* **enableDwell** `bool` clic par maintien&nbsp;: cliquer en laissant reposer le pointeur. Désactivé par défaut&nbsp;: il n'est utilisable qu'avec un eye tracker, et avec une souris il se déclenche sur ce qui se trouvait sous le pointeur (le menu d'accessibilité basculant le zoom ou le clavier à l'écran, typiquement)
* **dwellTime** `float` Délai du clic par maintien en secondes.
* **enableTrackerAuto** `bool` Eye tracker branché&nbsp;: contrôle de la souris au regard et clic au survol de Talon activés&nbsp;; débranché&nbsp;: clic au survol désactivé (session Cinnamon). Prend le pas sur `enableDwell` dans Cinnamon.
* **gazeFilterSpeed** `nullOr numbers.positive` Coefficient du filtre de regard par œil de Talon Control Mouse, avec `enableTrackerAuto`&nbsp;: plus haut réagit plus vite et lisse moins. Défaut&nbsp;: celui de Talon, la tête affine les derniers millimètres&nbsp;; `null` conserve celui de Talon quelle que soit sa version.
* **cursorFilterSpeed** `nullOr numbers.positive` Coefficient du filtre de curseur de Talon Control Mouse, avec `enableTrackerAuto`&nbsp;: plus haut réagit plus vite, dépasse davantage. `null` conserve celui de Talon (2.0).
* **headSpeed** `nullOr numbers.positive` Sensibilité de Talon Head Control, avec `enableTrackerAuto` et `enableHeadControl`&nbsp;: au-dessus de 1 un léger mouvement de tête déplace le curseur, en dessous de 1 les mouvements amples et peu contrôlés sont amortis. `null` conserve celui de Talon (1).
* **enableGazeControl** `bool` Talon Gaze Control, avec `enableTrackerAuto`&nbsp;: le curseur suit le regard.
* **enableHeadControl** `bool` Talon Head Control, avec `enableTrackerAuto`&nbsp;: les mouvements de tête affinent le curseur placé par le regard (`headSpeed`). Désactivé pour une tête instable, qui entraîne le curseur hors du regard.
* **enableHeadJump** `bool` Talon Head Jump, avec `enableTrackerAuto`&nbsp;: un mouvement de tête amène le curseur sur le regard
* **enableMouseJump** `bool` Talon Mouse Jump, avec `enableTrackerAuto`&nbsp;: déplacer une vraie souris vers le regard y amène le curseur. Désactivé par défaut, il arrache le pointeur d'un aidant
* **enableGazeFocus** `bool` Talon Gaze Focus (expérimental), avec `enableTrackerAuto`&nbsp;: la fenêtre regardée reçoit le focus
* **panelHeight** `ints.between 40 96` Hauteur du panneau Cinnamon en pixels, ses icônes suivent (cibles du regard).
* **textScaling** `float` Facteur d'échelle du texte de la session Cinnamon (les boutons grandissent avec leurs libellés).
* **enablePanel** `bool` Panneau Cinnamon géré par DNF&nbsp;: lanceurs et fenêtres ouvertes séparés, contrôles de clic au survol (types de clic, zone de pause), menu d'accessibilité, bascule du clavier&nbsp;; ni icône Bluetooth ni barre d'angle. Réécrit à chaque activation.
* **enableMaximize** `bool` Les fenêtres d'application s'ouvrent maximisées (extension Cinnamon), le panneau reste à portée. Les dialogues, Onboard et les fenêtres à taille fixe gardent leur taille.
* **panelLaunchers** `listOf str` Lanceurs du panneau (ids de fichiers desktop), avec `enablePanel`.
* **menuFavorites** `listOf str` Favoris du menu Cinnamon (ids de fichiers desktop), réécrits à chaque activation. `dnf-umi-calibrate.desktop`, avec `enableTrackerAuto`, lance la calibration de l'eye tracker.
* **enableRofiMenu** `bool` Grille d'applications plein écran (rofi), hôte UMI uniquement&nbsp;: pages de grandes tuiles tournées par des boutons de bord, un clic lance, les panneaux de réglages exclus. Ouverte par le premier lanceur du panneau (avec `enablePanel`).
* **rofiGridResolution** `submodule` Page de la grille d'applications, en tuiles, avec `enableRofiMenu`. Le défaut 6 × 4 loge des icônes de 96 px sur un écran 1600×900&nbsp;; moins de tuiles les élargit.
  * **columns** `ints.between 1 12` Tuiles par ligne.
  * **rows** `ints.between 1 8` Rangées de tuiles par page.
* **hiddenApps** `listOf str` Applications masquées de la grille et du menu Cinnamon (ids de fichiers desktop), hôte UMI uniquement. Les lancements par id et les associations de fichiers fonctionnent toujours.
* **enableStkWithMouse** `bool` SuperTuxKart piloté à la souris seule, hôte UMI uniquement&nbsp;: le stick (ou les mouvements de souris) accélère, freine et dirige, clic gauche dérape, double clic tire, clic droit utilise la nitro. Installe le jeu, son lanceur exécute le convertisseur

### &#x1F3E0; darkone.home.video

Outils et applications vidéo.

Installe toujours le lecteur par défaut (`celluloid`, interface GTK4/libadwaita
sur mpv) et contrôle le reste par public : `enableTools` (ffmpeg, mlt, vlc,

Le processus bloqué conserve le nom D-Bus `org.gnome.Showtime`, si bien que
chaque lancement ultérieur est activé sur lui et ne fait silencieusement rien :
ni fenêtre, ni journal.
Non corrigé en amont en 50.0.
:::
