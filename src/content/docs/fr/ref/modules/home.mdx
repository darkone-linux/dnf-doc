### &#x1F3E0; darkone.home.ai

Outils d'IA de codage et utilitaires de support.

:::note[Flags]
- `darkone.home.ai.enable` interrupteur principal qui installe les paquets
  utilitaires (aichat, llm, fabric-ai, gh, lazygit, direnv, outils de
  qualité de code, etc.) et active le système de flags par agent ci-dessous.
- `darkone.home.ai.enable{Claude,OpenCode,Codex,Aider,Goose}` installe et
  configure chacun un agent d'IA de codage spécifique.
- `darkone.home.ai.preferLocal` combiné à un hôte `darkone.service.ai` local
  ollama, les agents utilisent par défaut le modèle local au lieu des APIs cloud.
:::

:::tip[Câblage par hôte]
Ce module lit `osConfig.darkone.service.ai.enable` pour détecter un
hôte ollama local. Sur ces hôtes, `gollama`, le CLI `ollama`, et les
modèles locaux par défaut pour Aider / OpenCode sont activés automatiquement.

`programs.gh` est activé avec l'extension `github-copilot-cli`.
OpenCode obtient deux serveurs MCP (filesystem, fetch) via `npx -y`.
Claude Code applique une matrice de permissions allow/ask/deny et un
hook de gouvernance RTK sur les appels Bash.
:::

:::caution[settings.json inscriptible]
Claude Code et Antigravity CLI réécrivent leur propre `settings.json` :
un magasin en lecture seule en symlink les casse, et fait échouer le
prochain switch sur le `.bkp`. Le socle Nix est fusionné par jq dans un
fichier INSCRIPTIBLE à chaque switch ; les clés d'exécution (plugins,
espaces de travail de confiance) sont préservées.
:::

* **enable** `bool` Activer les outils d'IA et les utilitaires de support
* **enableClaude** `bool` CLI Claude Code
* **enableOpenCode** `bool` Agent d'IA terminal OpenCode
* **enableCodex** `bool` CLI OpenAI Codex
* **enableAntigravity** `bool` CLI Google Antigravity
* **enableAider** `bool` Programmation en binôme avec Aider AI
* **enableGoose** `bool` Agent de codage IA Goose (Block Inc.)
* **preferLocal** `bool` Préférer les modèles locaux plutôt que ceux du cloud

```nix
darkone.home.ai = {
  enable = false;
  enableClaude = false;
  enableOpenCode = false;
  enableCodex = false;
  enableAntigravity = false;
  enableAider = false;
  enableGoose = false;
  preferLocal = false;
};
```

### &#x1F3E0; darkone.home.audio

Outils et effets audio.

Installe un lecteur audio (`vlc`) et l'encodeur MP3 (`lame`)
sans condition, puis superpose les éditeurs et les effets (`audacity`,
`easyeffects` avec le préset `easyeffects-fw16`) lorsque `enableTools` est
défini. La réduction de bruit en temps réel (`noisetorch`) est intentionnellement désactivée
car elle nécessite PulseAudio.

* **enable** `bool` Outils audio
* **enableTools** `bool` Outils audio / éditeurs (audacity, easyeffect, noisetorch...)

```nix
darkone.home.audio = {
  enable = false;
  enableTools = false;
};
```

### &#x1F3E0; darkone.home.gnome

Réglages Gnome pour home-manager.

Masque sans condition les lanceurs `xterm` nu, les réglages Qt5/Qt6 et le
manuel NixOS, les Extensions pour les profils non techniques, enregistre des
entrées `.desktop` soignées pour `scrcpy` et `scrcpy-console` quand le paquet
fait partie des `home.packages` de l'utilisateur, et (quand `hideTechnicalIcons`
est défini) masque les icônes Paramètres, Imprimantes et File Roller pour les
profils débutant / enfant.

:::caution[Signets NFS]
Ne pas déclarer `gtk.gtk3.bookmarks` depuis ce module : tant que les partages
NFS du home sont actifs, `home/profiles/minimal/nfs.nix` possède ce fichier
et l'écrase.
:::

* **enable** `bool` Activer les réglages gnome pour home manager
* **hideTechnicalIcons** `bool` Masquer certaines icônes pour les débutants / enfants / petits

```nix
darkone.home.gnome = {
  enable = false;
  hideTechnicalIcons = false;
};
```

### &#x1F3E0; darkone.home.music

Applications graphiques de création musicale et sonore.

Classées par audience&nbsp;: `enablePro` (ardour, reaper, renoise,
rosegarden), `enableCreator` (decibels, hydrogen), `enableScore`
(musescore, muse-sounds-manager), `enableFun` (mixxx, mousai),
`enableCli` (mpg123, cmus, lilypond), `enableEasy` (gnome-music vs.

dans la même zone, MPD lit son répertoire musical depuis le montage NFS
(`/mnt/nfs/homes/$USER/Music`). Sinon il bascule sur la valeur locale
`srv-dirs.homes`, puis sur `~/Music`.

* **enablePro** `bool` Outils lourds pour professionnels (rose, ardour...)
* **enableFun** `bool` Outils audio amusants (mixxx...)

* **enableDev** `bool` Logiciels audio pour développeurs (lilypond...)
* **enableMpd** `bool` Démon MPD et lecteurs (mpd, ncmpcpp...)
* **enableEasy** `bool` Outils faciles plutôt qu'efficaces (gnome-music vs audacious...)
* **enableScore** `bool` Logiciels de partitions (musescore...)
* **enableCreator** `bool` Outils de création pour débutants (lmms, hydrogen...)

```nix

  enable = false;
```

* **enableUnsafeFeatures** `bool` Fonctionnalités pour utilisateurs avancés non-enfants
* **enableUBlock** `bool` Active le plugin ublock

* **enableProductivity** `bool` Applications de productivité (obsidian, time mgm, projects, etc.)
* **enableCommunication** `bool` Outils de communication
* **enableOffice** `bool` Paquets bureautiques (libreoffice, huntspell, polices...)

* **enableChromium** `bool` Active Chromium
* **enableBrave** `bool` Active Brave Browser
* **enableEmail** `bool` Paquets de gestion de courriel (thunderbird)
* **enableSecurity** `bool` Outils de sécurité (keepass)
* **enableCalendarContacts** `bool` Calendrier, contacts, tâches et applications associées
* **enableEssentials** `bool` Outils essentiels
* **huntspellLang** `str` [Langue Huntspell](https://mynixos.com/nixpkgs/packages/hunspellDicts)
* **enableElementAutoStart** `bool` Démarrage automatique d'Element Desktop à la connexion lorsqu'un serveur Matrix local est présent
* **enableFractalAutoStart** `bool` Démarrage automatique de Fractal à la connexion lorsqu'un serveur Matrix local est présent (opt-in, voir les mises en garde ci-dessous)
* **nextcloud.enable** `bool` Installe le client de bureau Nextcloud, pré-lié à l'instance du réseau
* **nextcloud.server** `nullOr str` Instance Nextcloud à laquelle le client se lie. `null` retient celle déclarée
  sur le réseau (cette zone d'abord). Définissez-la pour cibler plutôt une instance
  locale ou externe.
* **nextcloud.enableAutoStart** `bool` Démarre le client Nextcloud en arrière-plan à la connexion
* **nextcloud.enableWebdav** `bool` Fournit `nextcloud-webdav-login`, un assistant à usage unique qui authentifie
  via le navigateur (Kanidm SSO) et enregistre le résultat comme compte en ligne
  GNOME : fichiers via WebDAV dans le gestionnaire de fichiers, plus calendrier
  et contacts dans Evolution. Nécessaire car Nextcloud refuse de créer
  un mot de passe d'application depuis son interface web pour un utilisateur OIDC.

  L'assistant affiche également le mot de passe d'application, si bien que tout autre
  client WebDAV peut être pointé vers le même compte.

  :::note[GNOME uniquement]
  Le compte est écrit là où les comptes en ligne GNOME le lisent, que
  `darkone.graphic.gnome` active de lui-même dès que le réseau porte un cloud.
  Sur un autre bureau, le mot de passe affiché reste utilisable.
  :::

  Ignoré lorsque `darkone.home.office.nextcloud.enable` est désactivé.
* **nextcloud.syncDir** `nullOr str` Dossier local pré-rempli dans l'assistant de configuration, relatif à `$HOME`.

  :::caution[Aucune synchronisation par défaut]
  Laissé à `null` à dessein. L'assistant s'arrête alors sur sa page de dossier et
  l'utilisateur décide quoi synchroniser, le cas échéant. Le définir passe
  cette page.
  :::

```nix
  enableMore = false;
  enableUnsafeFeatures = false;
  enableUBlock = false;
  enableTools = false;
  enableProductivity = false;
  enableCommunication = false;
  enableOffice = false;
  enableFirefox = false;
  enableLibreWolf = false;
  enableChromium = false;
  enableBrave = false;
  enableEmail = false;
  enableSecurity = false;

  enableEssentials = true;
```

### &#x1F3E0; darkone.home.umi

Unified Multimodal Input (UMI)

Écran tactile + voix + regard (Talon démarrage automatique + Onboard).

:::note[Complémentaire au profil hôte umi]
L'hôte doit fournir udev/uinput et la session Cinnamon X11 (voir
`darkone.host.umi`, qui définit UMI). Ce module configure côté utilisateur : activation du
clic par stationnement (`enableDwell`), clavier Onboard ancré toujours visible avec
prédiction de mots et modificateurs persistants, et démarrage automatique de la session Talon.
:::

:::tip[Scripts communautaires]
Définir `communityScripts` sur un arbre github:talonhub/community récupéré pour obtenir
le contrôle vocal et du pavage oculaire (zoom souris, pop click) de manière déclarative.
:::

:::note[Doubles schémas]
La session UMI est Cinnamon (org/cinnamon/*) mais les clés GNOME
(org/gnome/*) restent synchronisées : mousetweaks lit le schéma d'accessibilité GNOME,
et ils servent de repli si l'utilisateur se retrouve un jour dans une session GNOME.
Exception : les clés verrouillées par le module DNF gnome ne sont jamais répliquées ici,
une écriture sur une clé verrouillée interrompt l'ensemble du `dconf load` de home-manager.
Le verrouillage d'écran reste activé côté GNOME (verrouillé par le module DNF gnome) ;
`idle-delay = 0` évite de le déclencher, et la session Cinnamon a son
propre verrouillage entièrement désactivé.
:::

:::caution[Trousseau de connexion : deux modes, décidés par l'hôte]
Une session de connexion automatique ne saisi aucun mot de passe, donc PAM n'a rien à transmettre
à gnome-keyring et chaque application utilisant des secrets affiche une invite gcr que l'utilisateur
UMI ne peut pas répondre. La façon d'éviter cela dépend de l'hôte :

- **Hôte non chiffré** : le trousseau de connexion est initialisé avec un mot de passe vide,
  que gnome-keyring stocke en texte clair et déverrouille de lui-même (il essaie
  un mot de passe vide avant de proposer une invite). Tout trousseau préexistant protégé par mot de passe
  est supprimé — sa phrase de passe est impossible à saisir ici, il ne peut donc que
  produire l'invite en permanence. La connexion automatique accorde déjà l'ensemble de la session à
  quiconque démarre la machine, il n'y a donc pas de perte de confidentialité réelle.
- **Hôte chiffré** (`darkone.system.luks.volumes` non vide) : rien n'est
  initialisé. La phrase de passe saisie au démarrage est mise en cache dans le trousseau noyau et
  transmise à gnome-keyring par `pam_gdm`, le trousseau reste donc chiffré avec
  elle. C'est le seul mode qui protège les secrets au repos.

Attention, hôtes chiffrés uniquement : la rotation de la phrase de passe LUKS (valeur
sops modifiée, `luks-passphrase-sync`) laisse le trousseau sur l'ancienne — GNOME
signale ensuite « Le mot de passe que vous utilisez pour vous connecter à votre ordinateur ne
correspond plus à celui de votre trousseau de connexion ». Supprimer
`~/.local/share/keyrings/login.keyring` et se reconnecter.
:::

* **enable** `bool` Configuration d'entrée multimodale UMI (Talon + Onboard)
* **enableTalonAutostart** `bool` Démarrer Talon à la connexion de la session (talon doit être dans PATH).
* **communityScripts** `nullOr package` Arbre talonhub/community déployé dans ~/.talon/user/community.
* **enableDwell** `bool` clic par stationnement : cliquer en reposant le pointeur. Désactivé par défaut — il n'est
  utilisable qu'avec un tracker oculaire, et avec une souris il se déclenche sur ce
  sur quoi le pointeur était positionné (le menu d'accessibilité activant le zoom ou le clavier
  à l'écran, typiquement)
* **dwellTime** `float` Délai du clic par stationnement en secondes.

```nix
darkone.home.umi = {
  enable = false;
  enableTalonAutostart = true;
  communityScripts = null;
  enableDwell = false;
  dwellTime = 1.2;
};
```

### &#x1F3E0; darkone.home.video

Outils et applications vidéo.

Installe par défaut le lecteur (`celluloid`, interface GTK4/libadwaita au-dessus de mpv)
et conditionne les autres par audience : `enableTools` (ffmpeg, mlt, vlc,
video-trimmer, parabolic), `enableEditing` (kdenlive + shotcut depuis stable
nixpkgs), `enableCreator` (OBS Studio avec `obs-backgroundremoval`,
`obs-vkcapture`, etc.), `enableUnfree` (davinci-resolve depuis stable),
et `enableAlternative` (mpv).

:::caution[Pas GNOME Showtime]
Showtime 50 se bloque sur certains fichiers — `get_state(CLOCK_TIME_NONE)` sur le
thread principal, [GNOME/showtime#299](https://gitlab.gnome.org/GNOME/showtime/-/work_items/299).
Le processus bloqué conserve le nom D-Bus `org.gnome.Showtime`, donc chaque
lancement ultérieur est activé vers celui-ci et ne fait rien silencieusement :
ni fenêtre, ni log.
Non corrigé en amont à la version 50.0.
:::

* **enable** `bool` Module maison de création et d'outils vidéo
* **enableTools** `bool` Outils vidéo pour professionnels
* **enableEditing** `bool` Outils de montage vidéo (kdenlive…)
* **enableCreator** `bool` Outils de création vidéo (obs…)
* **enableUnfree** `bool` Applications vidéo non libres (davinci…)
* **enableAlternative** `bool` Applications vidéo alternatives (mpv…)

```nix
darkone.home.video = {
  enable = false;
  enableTools = false;
  enableEditing = false;
  enableCreator = false;
  enableUnfree = false;
  enableAlternative = false;
};
```
