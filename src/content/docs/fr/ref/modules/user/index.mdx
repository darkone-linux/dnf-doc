**Un module de gestion des utilisateurs** gère les traitements liés aux utilisateurs ou des réglages spécifiques aux utilisateurs.

| Module | Rôle |
|---|---|
| [`build`](/fr/ref/modules/user/build/) | Construit la configuration NixOS des utilisateurs (pas home-manager). |
| [`root`](/fr/ref/modules/user/root/) | Réglages spécifiques à l'utilisateur root. |
