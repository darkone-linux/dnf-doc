Configuration de la localisation et de la langue.

:::note
Les valeurs par défaut suivent la zone du serveur (`etc/config.yaml`). La locale doit avoir la forme canonique `xx_YY.UTF-8` (ex. `fr_FR.UTF-8`) : la keymap de la console, la disposition XKB et la région du téléphone Nextcloud en dérivent.
:::

:::tip[Clavier d'une locale]
`dnf/config/locales.json` donne le clavier de chaque locale proposée par l'installeur (`en_GB.UTF-8` : `uk` sur la console, `gb` en XKB). Toute autre locale prend son code pays (`ru_RU.UTF-8` : `ru`).
:::

## Options

* **enable** `bool` Activer l'i18n avec la configuration de zone réseau par défaut
* **locale** `strMatching dnfLib.localeRegex` Locale réseau, doit respecter la forme `xx_YY.UTF-8`.
* **timeZone** `str` Fuseau horaire réseau
* **keyboard** `raw` Clavier de la locale : keymap `console`, disposition `xkb` et `xkbVariant`.

```nix
darkone.system.i18n = {
  enable = false;
  locale = "fr_FR.UTF-8";
  timeZone = "Europe/Paris";
  keyboard = if cfg.enable then
          dnfLib.keyboardFromLocale cfg.locale
        else
          {
            console = config.console.keyMap;
            xkb = config.console.keyMap;
            xkbVariant = "";
          };
};
```
