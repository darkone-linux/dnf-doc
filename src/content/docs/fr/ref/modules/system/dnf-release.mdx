Appose la version du framework sur l'hôte : `/etc/dnf-release` et l'étiquette de démarrage.

Répond à la question « quelle DNF fait tourner cette machine&nbsp;? » sans journal de déploiement, sur une flotte où les hôtes sont mis à jour un par un, et où un retour arrière peut laisser un nœud plusieurs versions en retard.

:::note[Sans condition]
Pas d'option `enable` : métadonnées pures, aucun service, aucun coût. `dnfVersion` vient de `lib/flake/mk-configuration.nix`, qui lit `dnf/VERSION` et la révision du flake.
:::

:::tip[Consulter-le]
```sh
cat /etc/dnf-release      # DNF_RELEASE + DNF_REV
nixos-version             # release appears as a `dnf-X.Y.Z` label tag
```
:::
