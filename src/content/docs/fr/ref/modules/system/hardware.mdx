Améliorations de la configuration matérielle.

Tous les micrologiciels sont chargés (`hardware.enableAllFirmware`), sauf sur une machine virtuelle&nbsp;: `just detect-hw` la détecte (`systemd-detect-virt --vm`) et définit `darkone.system.hardware.virtual` dans `hardware/detected-hardware.nix`. Un invité permet aussi à Zed de tourner sur son GPU émulé (`ZED_ALLOW_EMULATED_GPU`).

{/* t:p 350a8bfe11b9f68f8333463a4b6d32ab7c8b432b1a82ea1836c9c6a9e354bd19 */}
## Options

* **enable** `bool` Active les optimisations matérielles
* **enableIntel** `bool` Active les mises à jour du microcode Intel
* **enableAmd** `bool` Active les mises à jour du microcode AMD
* **virtual** `bool` Machine virtuelle, aucun micrologiciel chargé. Défini par `just detect-hw`

```nix
darkone.system.hardware = {
  enable = false;
  enableIntel = false;
  enableAmd = false;
  virtual = false;
};
```
