**Un module système** gère les configurations courantes, importantes et générales.

| Module | Rôle |
|---|---|
| [`core`](/fr/ref/modules/system/core/) | Le module DNF principal. |
| [`dnf-release`](/fr/ref/modules/system/dnf-release/) | Estampe la version du framework sur l'hôte : `/etc/dnf-release` et le libellé de démarrage. |
| [`dns`](/fr/ref/modules/system/dns/) | Résolveurs DNS publics du parc. |
| [`documentation`](/fr/ref/modules/system/documentation/) | Documentation (man) pour les développeurs et les administrateurs. |
| [`hardware`](/fr/ref/modules/system/hardware/) | Améliorations de la configuration matérielle. |
| [`i18n`](/fr/ref/modules/system/i18n/) | Configuration de la localisation et de la langue. |
| [`luks`](/fr/ref/modules/system/luks/) | Politique des phrases de passe LUKS &amp; déverrouillage à distance : phrases de passe partagées + par hôte, SSH initrd. |
| [`microvm`](/fr/ref/modules/system/microvm/) | Invités MicroVM (microvm.nix, cloud-hypervisor) sur un hôte hyperviseur DNF. |
| [`network`](/fr/ref/modules/system/network/) | Configuration réseau de l'ensemble du parc des hôtes DNF. |
| [`security`](/fr/ref/modules/system/security/) | Durcissement système ANSSI BP-028 v2.0 (GNU/Linux). (en cours) |
| [`services`](/fr/ref/modules/system/services/) | Registre des services DNF : chaque module de service s'y enregistre, et le registre est résolu selon la topologie du réseau. |
| [`sops`](/fr/ref/modules/system/sops/) | Gestion des mots de passe et des secrets avec DNF sops. |
| [`srv-dirs`](/fr/ref/modules/system/srv-dirs/) | Service de gestion des répertoires partagés. |
| [`testing`](/fr/ref/modules/system/testing/) | Mode de test autonome pour le NixOS Test Driver. |
| [`yubikey`](/fr/ref/modules/system/yubikey/) | Authentification forte YubiKey : PAM U2F sur tout le parc + LUKS FIDO2 déclaratif. |
