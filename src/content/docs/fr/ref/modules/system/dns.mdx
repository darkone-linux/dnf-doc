Résolveurs DNS publics du parc.

Une option choisit les opérateurs publics auxquels chaque résolveur DNF
envoie les noms Internet. Les adresses proviennent du catalogue
`dnfLib.publicResolvers` (`lib/dns.nix`)&nbsp;; chaque consommateur en dérive sa
propre forme&nbsp;:

| Composant | Usage | Forme |
|---|---|---|
| unbound du HCS (`headscale`) | relais des noms publics | DoT, vérifié par nom |
| AdGuard Home (passerelle) | `bootstrap_dns` | DNS en clair, IPv4 et IPv6 |
| AdGuard Home (passerelle) | `fallback_dns` | DoT par adresse IP |
| dnsmasq (passerelle) | serveurs de secours | DNS en clair, première IPv4 de chacun |

Hors de cette sélection&nbsp;: l'upstream filtrant d'AdGuard Home (AdGuard DNS,
une politique de filtrage) et les sondes ICMP (`internetProbeTargets`).

```nix
# usr/modules/dns.nix: back to Quad9 once it serves the country again
{ darkone.system.dns.publicResolvers = [ "quad9" "cloudflare" ]; }
```

:::caution[Deux opérateurs, les mêmes sur le HCS et les passerelles]
Vérifié à l'évaluation&nbsp;: un opérateur refusant un pays entier (Quad9,
France, 2026-11-24) ne doit pas interrompre le DNS du parc. Appliquez ce réglage
à tout le parc (`usr/modules/`), puis déployez le HCS et chaque passerelle.
:::

## Options

* **publicResolvers** `listOf (enum (lib.attrNames dnfLib.publicResolvers))` Opérateurs DNS publics (`dnfLib.publicResolvers`) auxquels l'unbound du HCS, AdGuard Home et dnsmasq envoient les noms Internet.

```nix
darkone.system.dns.publicResolvers = [ ];
```
