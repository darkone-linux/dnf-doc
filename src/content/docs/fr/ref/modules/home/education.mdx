## Options

* **enable** `bool` Collection de logiciels éducatifs
* **enableBaby** `bool` Logiciels éducatifs pour les bébés (&lt;=6 ans)
* **enableChild** `bool` Logiciels éducatifs pour les enfants (6-12 ans)
* **enableStudent** `bool` Logiciels éducatifs pour les adolescents et adultes (&gt;=12 ans)
* **enableMath** `bool` Outils et applications de mathématiques
* **enableMusic** `bool` Outils et applications de musique
* **enableScience** `bool` Outils et applications scientifiques
* **enableDraw** `bool` Outils et applications de dessin
* **enableLang** `bool` Outils et applications de langues
* **enableMisc** `bool` Outils et applications divers (général, entraînement...)
* **enableComputer** `bool` Outils et applications d'informatique (klavaro, etc.)
* **excludePackages** `listOf package` Logiciels des thèmes activés à ne pas installer, par nom.

```nix
darkone.home.education = {
  enable = false;
  enableBaby = false;
  enableChild = false;
  enableStudent = false;
  enableMath = true;
  enableMusic = true;
  enableScience = true;
  enableDraw = true;
  enableLang = true;
  enableMisc = true;
  enableComputer = true;
  excludePackages = [ ];
};
```
