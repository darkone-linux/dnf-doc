Logiciels de traitement d'images.

Installe toujours l'éditeur (`gimp`) ; la visionneuse (`geeqie`) fait partie des indispensables bureautiques. Ensuite, les outils s'ajoutent selon le public : `enableBeginner` ajoute `pinta`, `enablePro` ajoute `inkscape`/`krita`/`yed`, `enable3D` (avec `enablePro`) ajoute `blender`, `enableCAD` ajoute `freecad`, et `enableCli` ajoute `imagemagick`/`jhead`.

{/* t:p e88e41df17e754e4e203055dd1ed3a6a24e7461678a5482a3a7c01e1a34adce4 */}
## Options

* **enable** `bool` Création d'images
* **enablePro** `bool` Logiciels de traitement d'images supplémentaires pour professionnels
* **enableBeginner** `bool` Logiciels de traitement d'images supplémentaires pour débutants
* **enable3D** `bool` Logiciels 3D
* **enableCAD** `bool` Logiciels de CAO
* **enableCli** `bool` Outils en ligne de commande (imagemagick, jhead...)

```nix
darkone.home.imagery = {
  enable = false;
  enablePro = false;
  enableBeginner = false;
  enable3D = false;
  enableCAD = false;
  enableCli = false;
};
```
