Outils de codage IA et utilitaires associés.

:::note[Indicateurs]
- `darkone.home.ai.enable` : paquets utilitaires (aichat, llm, fabric-ai, gh,
  lazygit, direnv, Rust et outils de qualité de code) et les indicateurs d'agents ci-dessous.
- `darkone.home.ai.enable{Claude,OpenCode,Codex,Antigravity,Aider,Goose}` :
  un agent de codage IA chacun.
- `darkone.home.ai.preferLocal` : OpenCode utilise par défaut le modèle ollama local
  sur un hôte `darkone.service.ai`.
:::

:::tip[Branchements par hôte]
Sur un hôte ollama local (`darkone.service.ai`) : `gollama` et la CLI `ollama`,
et Aider se rabat sur le modèle local quand Claude est désactivé.

GitHub CLI (`gh`) et Copilot CLI (`copilot`) sont installés. Claude Code
applique une matrice de permissions autoriser/demander/refuser et un hook de gouvernance RTK sur
les appels Bash.
:::

:::caution[settings.json inscriptible]
Claude Code et Antigravity CLI réécrivent leur propre `settings.json` : un
lien symbolique vers un magasin en lecture seule les bloque, et fait échouer le
basculement suivant sur le `.bkp`. Le socle Nix est plutôt fusionné avec jq dans un
fichier INSCRIPTIBLE à chaque basculement ; les clés d'exécution (plugins, espaces de travail de confiance) sont conservées.
:::

## Options

* **enable** `bool` Activer les outils IA et les utilitaires associés
* **enableClaude** `bool` CLI Claude Code
* **enableOpenCode** `bool` Agent IA de terminal OpenCode
* **enableCodex** `bool` CLI OpenAI Codex
* **enableAntigravity** `bool` CLI Google Antigravity
* **enableAider** `bool` Aider, programmation en binôme avec l'IA
* **enableGoose** `bool` Agent de codage IA Goose (Block Inc.)
* **preferLocal** `bool` Préférer les modèles locaux aux modèles cloud

```nix
darkone.home.ai = {
  enable = false;
  enableClaude = false;
  enableOpenCode = false;
  enableCodex = false;
  enableAntigravity = false;
  enableAider = false;
  enableGoose = false;
  preferLocal = false;
};
```
