Outils d'agent d'un espace IA dans le home d'un membre : Claude Code, Codex, OpenCode, MCP, skills.

Tout provient de l'espace (`darkone.host.ai-space` de l'hôte), donc OpenClaw et chaque membre partagent les mêmes serveurs MCP et skills. Activé par défaut dans le home `space-member` ; désactivé sur tout autre hôte.

- MCP : HM `programs.mcp`, intégré à Claude Code, Codex et OpenCode ;
- skills : `~/.claude/skills`, `~/.codex/skills`, `~/.config/opencode/skills` ;
- connexions : une fois par membre, `claude` (`/login`), `codex login --device-auth`, `opencode auth login` ;
- `~/projects` : les projets partagés de l'espace (`projectsDir`).

:::note[Par membre, par espace]
`usr/users/<login>/spaces/<host>.nix` ajoute ou remplace, par exemple un serveur MCP personnel : `programs.mcp.servers.<name> = { ... };`.
:::

## Options

* **enable** `bool` Outils d'agent de l'espace IA (Claude Code, Codex, OpenCode, MCP, skills)

```nix
darkone.home.aiSpace.enable = false;
```
