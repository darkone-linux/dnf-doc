Applications par défaut (`xdg.mimeApps`) pour les documents, images, audio, vidéo.

Chaque type MIME liste des entrées de bureau par ordre de préférence&nbsp;: la première installée l'emporte. Papers (PDF), Geeqie (images), Celluloid (vidéo), Audacious (audio), GNOME Text Editor (texte brut), Zed (Markdown).
