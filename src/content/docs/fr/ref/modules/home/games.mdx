## Options

* **enable** `bool` Activer les jeux
* **enableBaby** `bool` Jeux pour bébés (&lt;=6 ans)
* **enableChild** `bool` Jeux pour enfants (6-12 ans)
* **enableTeenager** `bool` Jeux pour adolescents et adultes (&gt;=12 ans)
* **enable3D** `bool` Jeux 3D supplémentaires
* **enableCli** `bool` Jeux en ligne de commande
* **enableStk** `bool` SuperTuxKart (uniquement)
* **enableMore** `bool` Jeux secondaires supplémentaires dans chaque catégorie
* **excludePackages** `listOf package` Jeux des catégories activées à ne pas installer, par nom.
* **enableGnome** `bool` Activer les jeux GNOME populaires

```nix
darkone.home.games = {
  enable = false;
  enableBaby = false;
  enableChild = false;
  enableTeenager = false;
  enable3D = false;
  enableCli = false;
  enableStk = false;
  enableMore = false;
  excludePackages = [ ];
  enableGnome = true;
};
```
