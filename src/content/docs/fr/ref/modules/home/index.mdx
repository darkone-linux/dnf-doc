**Un module Home Manager** fonctionne avec les profils [Home Manager](https://github.com/nix-community/home-manager).

| Module | Rôle |
|---|---|
| [`advanced`](/fr/ref/modules/home/advanced/) | Profil de base pour utilisateurs avancés (informaticiens, développeurs, administrateurs). |
| [`ai`](/fr/ref/modules/home/ai/) | Outils de développement assistés par IA et utilitaires associés. |
| [`ai-space`](/fr/ref/modules/home/ai-space/) | Outils d'agents d'un espace IA dans le répertoire personnel d'un membre : Claude Code, Codex, OpenCode, MCP, skills. |
| [`audio`](/fr/ref/modules/home/audio/) | Outils et effets audio. |
| [`education`](/fr/ref/modules/home/education/) | Plusieurs paquets graphiques pour l'éducation. |
| [`games`](/fr/ref/modules/home/games/) | Plusieurs paquets graphiques de jeux. |
| [`gnome`](/fr/ref/modules/home/gnome/) | Réglages Gnome pour Home Manager. |
| [`imagery`](/fr/ref/modules/home/imagery/) | Logiciels de traitement d'images. |
| [`mime`](/fr/ref/modules/home/mime/) | Applications par défaut (`xdg.mimeApps`) pour documents, images, audio, vidéo. |
| [`music`](/fr/ref/modules/home/music/) | Applications graphiques de création musicale et sonore. |
| [`office`](/fr/ref/modules/home/office/) | Bureautique : navigateurs, suite bureautique, communication, outils cloud et PDF. |
| [`umi`](/fr/ref/modules/home/umi/) | Entrée multimodale unifiée (UMI) |
| [`video`](/fr/ref/modules/home/video/) | Outils et applications vidéo. |
