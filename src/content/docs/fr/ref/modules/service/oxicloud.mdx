OxiCloud — Cloud souverain rapide (stockage de fichiers, WebDAV, CalDAV et CardDAV).

:::note[Service en cours de validation]
Wrapper DNF autour du module nixpkgs (depuis la [PR #516113](https://github.com/NixOS/nixpkgs/pull/516113)).
Le paquet `oxicloud` est déjà fourni par nixpkgs ; seul le module est copié
depuis la PR (cf. `backports/nixos/oxicloud.nix`).
:::

:::tip[SSO]
Quand un service `idm` (Kanidm) existe sur le réseau (zone ou global), OIDC est
configuré automatiquement : un client OAuth2 est enregistré et OxiCloud est orienté
vers les points d'accès Kanidm. Sans `idm`, le comportement d'origine est conservé
(connexion par mot de passe local uniquement).
:::

:::caution[Comptes avec SSO]
- L'auto-inscription est fermée : les comptes sont créés à la première connexion SSO.
- Les membres du groupe Kanidm `admins` deviennent administrateurs OxiCloud uniquement
  à cette première connexion ; les changements de rôle ultérieurs se font dans l'interface
  d'administration d'OxiCloud.
:::

:::tip[Stockage et clients]
Le stockage de fichiers, WebDAV (`/webdav/`), CalDAV (`/caldav`) et CardDAV (`/carddav`)
sont servis sur le même port HTTP, derrière le reverse proxy Caddy. La couche de
compatibilité Nextcloud est activée : les clients Nextcloud de bureau et mobiles, ainsi que
le fournisseur Nextcloud de GNOME Comptes en ligne, se connectent à l'URL du service.
La base PostgreSQL est créée localement.
:::

:::tip[Courriel]
Quand `network.smtp` est défini, OxiCloud envoie les notifications de partage et les
invitations par courriel (liens magiques) via ce relais. Sans lui, les fonctions
de courriel sont désactivées.
:::
