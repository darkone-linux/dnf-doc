OxiCloud — Cloud souverain rapide (stockage de fichiers, WebDAV, CalDAV &amp; CardDAV).

:::note[Service en cours de validation]
Wrapper DNF autour du module nixpkgs (issu de [PR #516113](https://github.com/NixOS/nixpkgs/pull/516113)).
Le paquet `oxicloud` est déjà fourni par nixpkgs ; seul le module est copié
depuis la PR (cf. `backports/nixos/oxicloud.nix`).
:::

:::tip[SSO]
Lorsqu'un service `idm` (Kanidm) existe sur le réseau (zone ou global), l'OIDC est
configuré automatiquement : un client OAuth2 est enregistré et OxiCloud pointe vers
les points d'accès Kanidm. Sans `idm`, le comportement amont reste inchangé
(connexion par mot de passe local uniquement).
:::

:::caution[Comptes avec SSO]
- L'auto-inscription est fermée : les comptes sont créés lors de la première connexion SSO.
- Les membres du groupe Kanidm `admins` deviennent administrateurs OxiCloud uniquement lors de cette première connexion ; les changements de rôle ultérieurs se font dans l'interface d'administration OxiCloud.
:::

:::tip[Stockage et clients]
Le stockage de fichiers, WebDAV (`/webdav/`), CalDAV (`/caldav`) et CardDAV
(`/carddav`) sont servis sur le même port HTTP, derrière le proxy inverse Caddy.
La couche de compatibilité Nextcloud est activée : les clients de bureau et mobiles
Nextcloud, ainsi que le fournisseur Nextcloud de GNOME Online Accounts, se
connectent à l'URL du service. La base de données PostgreSQL est créée localement.
:::

:::tip[E-mail]
Lorsque `network.smtp` est défini, OxiCloud envoie les notifications de partage et
les invitations par e-mail (liens magiques) via ce relais, et envoie par courriel
les résultats des tâches planifiées (perte de données) à
`darkone.system.security.adminMailbox`. Sans cela, les fonctionnalités d'e-mail
sont désactivées et l'interface d'administration avertit qu'aucune destination de
notification n'est configurée.
:::
