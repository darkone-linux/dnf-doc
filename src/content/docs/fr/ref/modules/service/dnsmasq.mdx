dnsmasq préconfiguré pour la passerelle locale ou le routeur.

:::note
Cette configuration lit la section `network` du fichier `config.yaml`.
C'est la fonctionnalité essentielle de la passerelle locale.
:::

:::tip[Hôtes de passage depuis une autre zone]
Chaque zone réserve `<ipPrefix>.6.0/24` pour les hôtes dont le domicile est ailleurs.
Le générateur écrit, dans `zone.extraDnsmasqSettings`, un `dhcp-host` par adresse MAC connue de la flotte qui n'est pas native ici, plus un `host-record` liant `<host>.<this-zone-domain>` à cette adresse. Ainsi, une machine branchée dans la mauvaise zone (installation d'une passerelle, ordinateur portable itinérant) obtient quand même un bail prévisible et un nom. Son nom court continue de résoudre vers son adresse d'origine.
`zone.roaming` expose la même table à l'outillage d'installation.
:::
