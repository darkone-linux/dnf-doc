Serveur et client NFS pour les partages home.

:::note
Ce module est activé si un serveur nfs est déclaré dans le réseau local. Il crée :

- Un partage (srv-dirs.homes) sur le serveur.
- Des répertoires de montage (/mnt/nfs/homes/[user]) sur les clients.

Le script du gestionnaire de home nfs relie les répertoires xdg aux répertoires de montage.
Dans le fichier config.yaml (hôtes)&nbsp;:

- Un seul hôte a le service `service.nfs`.
- Les clients ont besoin de `features = [ "nfs-client" ]`.
:::

:::caution[Les exports sont par IP client]
Seuls les hôtes `nfs-client` déclarés de la zone apparaissent dans `/etc/exports`&nbsp;; une machine absente de `config.yaml` n'obtient aucun montage. Root est squashé sur chaque partage&nbsp;: le root d'un client est `nobody` sur le serveur.
:::

## Options

* **enable** `bool` Active le serveur NFS DNF (éviter de l'activer manuellement)
* **serverDomain** `str` FQDN du serveur NFS

```nix
darkone.service.nfs = {
  enable = hasServer && (isServer || isClient);
  serverDomain = "nfs";
};
```
