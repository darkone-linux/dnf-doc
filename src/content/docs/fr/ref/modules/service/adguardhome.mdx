Configuration complète d'AdGuard Home pour passerelle locale / routeur.

:::note
Cette configuration lit le fichier `config.yaml` (`network`).
Elle utilise le [module DNF dnsmasq](/fr/ref/modules/service/dnsmasq/) comme DNS amont et DHCP.
:::

## Options

* **enable** `bool` Active le service AdGuard Home local

```nix
darkone.service.adguardhome.enable = false;
```
