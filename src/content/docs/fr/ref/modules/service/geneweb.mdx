GeneWeb — Service de généalogie puissant.

:::note[Service en cours de validation]
Wrapper DNF autour du module nixpkgs (issu de [PR #522751](https://github.com/NixOS/nixpkgs/pull/522751)).
:::

:::tip[Déclaration d'une base]
Pour déclarer un fichier `base.gw` (le répertoire par défaut est `/var/lib/geneweb`),
ajoutez ceci à la configuration de votre serveur :
```nix
services.geneweb.databases.base = {};
```
:::

:::caution[Secrets SOPS]
L'option `enablePasswords` lit les mots de passe ami et wizard depuis les secrets
sops `geneweb-friend` et `geneweb-wizard`. Si elle est activée, ajoutez les entrées dans
`usr/secrets/` avant de reconstruire, sinon l'activation de sops-nix échouera.

**Remarque importante :** les mots de passe sops doivent être transmis en clair au
démon Geneweb. Pour plus de sécurité, il est préférable de définir ces mots de passe dans
le fichier de configuration de la base (votre-base.gwf) plutôt que d'utiliser `enablePasswords`.
:::

## Options

* **enable** `bool` Activer le service local de généalogie GeneWeb
* **enablePasswords** `bool` Activer les mots de passe sops (déconseillé)

```nix
darkone.service.geneweb = {
  enable = false;
  enablePasswords = false;
};
```
