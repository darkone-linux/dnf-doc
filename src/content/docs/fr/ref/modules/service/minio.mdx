Un service MinIO S3 local, entièrement configuré. (wip)

Fournit un backend de stockage d'objets interne, compatible S3, accessible uniquement sur 127.0.0.1:9000. La console web tourne sur 127.0.0.1:9001 pour l'administration et le débogage.

:::note
Les buckets ne sont PAS créés automatiquement par ce module.
Chaque service consommateur crée ses propres buckets via un hook systemd postStart, avec l'outil `mc` (MinIO Client).
Les identifiants sont gérés avec sops.
:::
