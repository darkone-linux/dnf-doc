**Un module de service** fournit un service prêt à l'emploi (démon).

| Module | Rôle |
|---|---|
| [`adguardhome`](/fr/ref/modules/service/adguardhome/) | AdGuard Home entièrement configuré pour passerelle / routeur local. |
| [`ai`](/fr/ref/modules/service/ai/) | Intelligence artificielle locale (open-webui + ollama + llms). |
| [`audio`](/fr/ref/modules/service/audio/) | Services audio : alsa, pulse (pas jack pour le moment). Ajoute automatiquement les utilisateurs au groupe `audio` à l'activation. |
| [`dnsmasq`](/fr/ref/modules/service/dnsmasq/) | dnsmasq préconfiguré pour passerelle / routeur local. |
| [`docs`](/fr/ref/modules/service/docs/) | Module LaSuite Docs entièrement configuré. |
| [`element`](/fr/ref/modules/service/element/) | Client web Element pour le service matrix local. |
| [`fail2ban`](/fr/ref/modules/service/fail2ban/) | Module Fail2ban propre à DNF. |
| [`forgejo`](/fr/ref/modules/service/forgejo/) | Forge git forgejo entièrement configurée. |
| [`garage`](/fr/ref/modules/service/garage/) | Service S3 Garage local entièrement configuré. |
| [`geneweb`](/fr/ref/modules/service/geneweb/) | GeneWeb : service de généalogie puissant. |
| [`harmonia`](/fr/ref/modules/service/harmonia/) | Harmonia : serveur local de cache binaire Nix (sert le /nix/store de cet hôte). |
| [`headscale`](/fr/ref/modules/service/headscale/) | Service headscale entièrement configuré pour HCS. |
| [`home-assistant`](/fr/ref/modules/service/home-assistant/) | Home Assistant avec quelques plugins (en cours). |
| [`homepage`](/fr/ref/modules/service/homepage/) | Tableau de bord homepage configuré dynamiquement pour votre réseau local. |
| [`idm`](/fr/ref/modules/service/idm/) | Service DNF Kanidm (gestionnaire d'identités). |
| [`immich`](/fr/ref/modules/service/immich/) | Service Immich (gestion de photos) entièrement configuré. |
| [`jellyfin`](/fr/ref/modules/service/jellyfin/) | Serveur jellyfin entièrement configuré. |
| [`jitsi-meet`](/fr/ref/modules/service/jitsi-meet/) | Service jitsi-meet entièrement configuré. |
| [`loki`](/fr/ref/modules/service/loki/) | Loki + Alloy, statistiques http avec grafana. |
| [`matrix`](/fr/ref/modules/service/matrix/) | Serveur d'accueil matrix (synapse) DNF. |
| [`matrix-admin`](/fr/ref/modules/service/matrix-admin/) | Interface d'administration Matrix (Ketesa, anciennement synapse-admin) pour le serveur local. |
| [`mealie`](/fr/ref/modules/service/mealie/) | Gestion de recettes Mealie |
| [`minio`](/fr/ref/modules/service/minio/) | Service S3 MinIO local entièrement configuré. (en cours) |
| [`monitoring`](/fr/ref/modules/service/monitoring/) | Module de supervision : tableaux de bord Grafana + exporteur par nœud. |
| [`nextcloud`](/fr/ref/modules/service/nextcloud/) | Service Nextcloud entièrement configuré. |
| [`nfs`](/fr/ref/modules/service/nfs/) | Serveur + client NFS pour les partages personnels. |
| [`nix-cache`](/fr/ref/modules/service/nix-cache/) | Proxy de cache binaire Nix par zone (`proxy_cache` nginx). |
| [`openclaw`](/fr/ref/modules/service/openclaw/) | Assistant OpenClaw d'un espace IA (passerelle + interface de contrôle, derrière le SSO de la zone). |
| [`outline`](/fr/ref/modules/service/outline/) | Wiki outline entièrement configuré. |
| [`oxicloud`](/fr/ref/modules/service/oxicloud/) | OxiCloud : cloud souverain rapide (stockage de fichiers, WebDAV, CalDAV &amp; CardDAV). |
| [`postfix`](/fr/ref/modules/service/postfix/) | Relais SMTP Postfix. |
| [`printing`](/fr/ref/modules/service/printing/) | Imprimantes et scanners. |
| [`prometheus`](/fr/ref/modules/service/prometheus/) | Serveur de supervision Prometheus avec escalade Alertmanager déclarative. |
| [`restic`](/fr/ref/modules/service/restic/) | Module de sauvegarde Restic : serveur REST + cibles de sauvegarde par hôte. |
| [`searx`](/fr/ref/modules/service/searx/) | Moteur de recherche searx durci et entièrement configuré. |
| [`stk`](/fr/ref/modules/service/stk/) | Circuits SuperTuxKart partagés, servis par NFS. |
| [`tailscale`](/fr/ref/modules/service/tailscale/) | Client Tailscale du tailnet DNF (headscale sur le HCS). |
| [`turn`](/fr/ref/modules/service/turn/) | Serveur Coturn (matrix). |
| [`vaultwarden`](/fr/ref/modules/service/vaultwarden/) | Serveur vaultwarden entièrement configuré. |
