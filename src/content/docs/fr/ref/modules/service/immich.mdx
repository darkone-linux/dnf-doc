## Options

* **enable** `bool` Activer le service Immich local
* **enableMachineLearning** `bool` Activer les fonctions d'apprentissage automatique (reconnaissance faciale, détection d'objets)
* **enableRedis** `bool` Activer Redis pour le cache (recommandé pour les performances)

```nix
darkone.service.immich = {
  enable = false;
  enableMachineLearning = false;
  enableRedis = false;
};
```
