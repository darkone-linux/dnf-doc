## Options

* **enable** `bool` Active le service de documents local
* **s3Host** `str` Nom d'hôte du backend S3
* **s3Port** `port` Port du backend S3
* **s3Bucket** `str` Nom du bucket S3 de stockage des documents

```nix
darkone.service.docs = {
  enable = false;
  s3Host = "127.0.0.1";
  s3Port = dnfConfig.network.ports.garage;
  s3Bucket = "docs";
};
```
