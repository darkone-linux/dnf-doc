Une forge git Forgejo entièrement configurée.

:::note[Accès SSH]
Les push et pull en SSH passent par `AuthorizedKeysCommand`, et non par le fichier `authorized_keys` que Forgejo écrit dans son répertoire personnel&nbsp;: `core.nix` définit `authorizedKeysInHomedir = false`, donc sshd ne lit jamais ce fichier.
:::

## Options

* **enable** `bool` Active le service Forgejo local

```nix
darkone.service.forgejo.enable = false;
```
