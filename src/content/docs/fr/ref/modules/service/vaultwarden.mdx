Un serveur Vaultwarden entièrement configuré.

:::note[Panneau d'administration]
`/admin` ne répond qu'au LAN et au tailnet. Les zones et le tailnet résolvent le service vers l'IP tailnet du HCS. Les clients Bitwarden (web, extension, mobile) restent publics.
:::

{/* t:p 67b72ef9ddf257f49848ee69490eb082210ed7781aabf856ca4d9c4cc109dce2 */}
## Options

* **enable** `bool` Activer le service Vaultwarden local
* **enableSmtp** `bool` Activer SMTP pour envoyer des e-mails (recommandé, nécessite `network.smtp`)

```nix
darkone.service.vaultwarden = {
  enable = false;
  enableSmtp = true;
};
```
