Page d’accueil du premier démarrage de l’hôte d’administration installé par `darkone new`.

À la première session GNOME de chaque membre de `wheel`, le navigateur ouvre une page locale&nbsp;: étape 1 sur 4 terminée (l’hôte d’administration), la passerelle ensuite, puis les services et le serveur de coordination, avec des liens vers la documentation. Affichée une seule fois par utilisateur (`~/.local/state/dnf/welcome-shown`). Le lanceur «&nbsp;Onboarding&nbsp;» du nix-admin permet de la rouvrir (`darkone.admin.welcome.command`).

L’étape 2 est marquée comme terminée dès que la zone de cet hôte dispose d’une passerelle (`network`, lu au moment de la construction&nbsp;: `darkone add gateway` se termine par `just apply-local`).

Tant que le témoin `/var/lib/dnf/backup-admin` de `just backup-admin` est absent, la page s’ouvre avec une bannière&nbsp;: les clés d’administration ne sont pas sauvegardées.

:::note[Défini par l’installateur]
`darkone new` écrit `darkone.admin.welcome.enable = true;` dans le
`configuration.nix` de l’hôte d’administration. Supprimez la ligne pour ne plus afficher la page aux utilisateurs qui ne l’ont pas encore vue.
:::

## Options

* **enable** `bool` la page d'accueil de premier démarrage de l'hôte admin
* **command** `path` Le script qui ouvre la page d'accueil, `--again` pour la rouvrir

```nix
darkone.admin.welcome = {
  enable = false;
  command = open;
};
```
