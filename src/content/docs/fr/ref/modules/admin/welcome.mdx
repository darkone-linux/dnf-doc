Page d'accueil de premier démarrage de l'hôte admin installée par `darkone new`.

À la première session GNOME de chaque membre du groupe `wheel`, le navigateur ouvre une page locale : étape 1 sur 4 terminée (l'hôte admin), la passerelle ensuite, puis les services et le serveur de coordination, avec des liens vers la documentation. Affichée une fois par utilisateur (`~/.local/state/dnf/welcome-shown`). Le lanceur « Onboarding » du nix-admin la rouvre (`darkone.admin.welcome.command`).

Tant que le témoin `/var/lib/dnf/backup-admin` de `just backup-admin` est absent, la page s'ouvre avec une bannière : les clés admin ne sont pas sauvegardées.

:::note[Défini par l'installateur]
`darkone new` écrit `darkone.admin.welcome.enable = true;` dans le `configuration.nix` de l'hôte admin. Retirer la ligne pour arrêter la page pour les utilisateurs qui ne l'ont pas encore vue.
:::

## Options

* **enable** `bool` la page d'accueil de premier démarrage de l'hôte admin
* **command** `path` Le script qui ouvre la page d'accueil, `--again` pour la rouvrir

```nix
darkone.admin.welcome = {
  enable = false;
  command = open;
};
```
