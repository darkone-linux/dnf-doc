**Un module d'administration** gère les fonctionnalités système propres aux administrateurs.

| Module | Rôle |
|---|---|
| [`fleet-update`](/fr/ref/modules/admin/fleet-update/) | Outil de mise à jour de la flotte (`fleet-update`) et son exécution quotidienne sans surveillance. |
| [`locate`](/fr/ref/modules/admin/locate/) | Localisateur d'hôtes de la flotte (`dnf-locate`) : ssh trouve un hôte où qu'il soit branché. |
| [`nix`](/fr/ref/modules/admin/nix/) | Configuration NixOS du poste administrateur du LAN local. |
| [`welcome`](/fr/ref/modules/admin/welcome/) | Page d'accueil au premier démarrage de l'hôte administrateur installé par `darkone new`. |
