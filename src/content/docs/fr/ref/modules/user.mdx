### &#x1F464; darkone.user.build

Construit la configuration NixOS des utilisateurs (pas home-manager).

:::danger[Module requis]
Ce module est activé par défaut (requis par la configuration DNF).
:::

:::note[Refus SSH par groupe logique]
`sshDeniedGroups` (défaut `guests`) s'étend en `DenyUsers` sur chaque hôte : un
membre conserve sa session locale et perd l'accès SSH.
:::

* **enable** `bool` Constructeur d'utilisateurs commun (activé par défaut)
* **sshDeniedGroups** `listOf str` Groupes logiques (`config.yaml`) dont les membres ne doivent jamais ouvrir de
  session SSH. Expansé par hôte en `services.openssh.settings.DenyUsers`.

```nix
darkone.user.build = {
  enable = true;
  sshDeniedGroups = [ ];
};
```

### &#x1F464; darkone.user.root

Paramètres spécifiques de l'utilisateur root.

:::danger[Module obligatoire]
Ce module est activé par défaut (requis par la configuration DNF).
:::

* **enable** `bool` Configuration spécifique de l'utilisateur root

```nix
darkone.user.root.enable = true;
```
