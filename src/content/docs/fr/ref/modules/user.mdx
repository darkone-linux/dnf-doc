### &#x1F464; darkone.user.build

Construit la configuration NixOS des utilisateurs (pas home-manager).

:::danger[Module obligatoire]
Ce module est activé par défaut (requis par la configuration DNF).
:::

:::note[Interdiction SSH par groupe logique]
`sshDeniedGroups` (par défaut `guests`) se déploie en `DenyUsers` sur chaque
hôte : un membre conserve sa session locale et perd le SSH.
:::

:::note[registre authorized_keys]
`usr/users/<login>/authorized_keys` (espace de travail consommateur, versionné,
format OpenSSH) alimente `openssh.authorizedKeys` sur chaque hôte de
l'utilisateur. Fichier absent = aucune clé ; compte désactivé = fichier ignoré.
Les clés privées ne vivent jamais dans l'espace de travail : elles restent dans
le coffre Vaultwarden de chaque utilisateur (cf. `rbw`).
:::

* **enable** `bool` Constructeur commun des utilisateurs (activé par défaut)
* **sshDeniedGroups** `listOf str` Groupes logiques (`config.yaml`) dont les membres ne doivent jamais ouvrir de session
  SSH. Déploiement par hôte dans `services.openssh.settings.DenyUsers`.

```nix
darkone.user.build = {
  enable = true;
  sshDeniedGroups = [ ];
};
```

### &#x1F464; darkone.user.root

Paramètres spécifiques de l'utilisateur root.

:::danger[Module obligatoire]
Ce module est activé par défaut (requis par la configuration DNF).
:::

* **enable** `bool` Configuration spécifique de l'utilisateur root

```nix
darkone.user.root.enable = true;
```
