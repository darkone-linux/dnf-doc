## Options

* **enable** `bool` Installation Virtualbox préconfigurée
* **enableExtensionPack** `bool` Active le pack d'extensions (provoque des recompilations)

```nix
darkone.graphic.virtualbox = {
  enable = false;
  enableExtensionPack = false;
};
```
