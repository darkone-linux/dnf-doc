**Un module d'applications graphiques** installe des applications graphiques et leur configuration, optimisées pour DNF.

| Module | Rôle |
|---|---|
| [`gnome`](/fr/ref/modules/graphic/gnome/) | Environnement gnome préconfiguré, avec ses dépendances. |
| [`qemu`](/fr/ref/modules/graphic/qemu/) | VM de test QEMU, reliées au LAN DNF par pont réseau |
| [`remote-desktop`](/fr/ref/modules/graphic/remote-desktop/) | Bureau distant d'administration : se rattacher à une session graphique ouverte, ou en ouvrir une, via RDP. |
| [`supertuxkart`](/fr/ref/modules/graphic/supertuxkart/) | SuperTuxKart, configuré pour jouer en réseau local. |
| [`virt-manager`](/fr/ref/modules/graphic/virt-manager/) | Virt-manager et visionneuse avec spice, win-virtio et ovmf. |
| [`virtualbox`](/fr/ref/modules/graphic/virtualbox/) | Installation de l'hôte VirtualBox. |
