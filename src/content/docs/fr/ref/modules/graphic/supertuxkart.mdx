SuperTuxKart avec configurations pour jouer en réseau local.

:::tip
À utiliser avec le module games de homemanager !
:::

:::note[Pistes partagées]
Le partage des pistes lui-même se trouve dans `service/stk.nix`. `enableNfsClient` et `nfsServer` sont les seuls réglages qu'un hôte doit renseigner : ils configurent `darkone.service.stk.{enableClient,serverName}`, pour qu'une configuration de machine n'ait jamais à nommer deux modules pour un seul jeu.
:::

:::tip[Jouer entre zones]
Les ports de jeu et de découverte acceptent tous les préfixes de zone et le tailnet. La découverte par diffusion reste dans la zone : depuis une autre zone, rejoindre avec « Enter server address » (IP du serveur, port 2759).
:::

:::tip[Câble direct, sans réseau]
`enableDirectLink` : deux hôtes reliés par un simple câble Ethernet (sans DHCP, sans Internet). Sur les deux, choisir le profil `STK direct cable` dans le menu filaire de GNOME (adresses link-local), puis Online → Local Networking.
:::

:::caution[Pare-feu limité à la flotte]
Les sources sont filtrées par préfixes de flotte, jamais par interface : un hôte STK qui possède aussi une adresse WAN ne publie pas le jeu là-bas.
:::

## Options

* **enable** `bool` SuperTuxKart + configuration du pare-feu
* **enableNfsClient** `bool` Monte les pistes partagées du serveur `stk` de la zone
* **nfsServer** `nullOr str` Nom d'hôte servant les pistes, par défaut l'hôte du service `stk` de la zone
* **enableDirectLink** `bool` Jouer par câble Ethernet direct, sans DHCP (profil NetworkManager `${directLinkProfile}`)

```nix
darkone.graphic.supertuxkart = {
  enable = false;
  enableNfsClient = false;
  nfsServer = null;
  enableDirectLink = false;
};
```
