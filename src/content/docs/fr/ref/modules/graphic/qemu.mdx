VM de test QEMU ponterées sur le LAN DNF

Utilisé par `dnf/scripts/vm-start.sh`.
Intègre la carte réseau filaire dans un pont NetworkManager et permet aux utilisateurs non privilégiés de connecter des VM à ce pont via le `qemu-bridge-helper` setuid. Une VM obtient alors son adresse depuis la passerelle de zone, comme une machine physique, ainsi `just full-install <host> nixos <ip>` peut l'atteindre.

:::caution[Adresse MAC du pont]
`bridge.macAddress` doit être l'adresse MAC de la carte elle-même : le pont reprend l'IP de l'hôte, et la réservation DHCP de la zone (`mac` dans `etc/config.yaml`) s'appuie dessus.
:::

:::note[Activation]
Le déploiement charge seulement les profils. Redémarrer, ou lancer `nmcli connection up br0`, pour déplacer l'IP de l'hôte sur le pont.
:::

```nix
darkone.graphic.qemu = {
  enable = true;
  bridge.interface = "enp2s0";
  bridge.macAddress = "aa:bb:cc:dd:ee:ff";
};
```

## Options

* **enable** `bool` VM de test QEMU ponterées sur le LAN DNF
* **bridge.name** `str` Interface du pont à laquelle les VM se connectent.
* **bridge.interface** `str` Carte réseau filaire intégrée au pont.
* **bridge.macAddress** `str` Adresse MAC du pont : celle de la carte elle-même, pour garder la réservation DHCP de la zone.

```nix
darkone.graphic.qemu = {
  enable = false;
  bridge.name = "br0";
  bridge.interface = "enp2s0";
  bridge.macAddress = "aa:bb:cc:dd:ee:ff";
};
```
