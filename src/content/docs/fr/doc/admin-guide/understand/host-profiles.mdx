Un **profil d'hôte** est un gabarit qui définit le rôle d'une machine. On le
choisit avec `profile:` dans `etc/config.yaml`. Les profils s'héritent : chacun
part d'un autre et ajoute ses spécificités.

## Les profils

| Profil | Pour quoi | Hérite de | Apporte |
|---|---|---|---|
| `minimal` | Base de tout hôte | | Matériel, pare-feu, i18n, zsh, sudo |
| `server` | Serveur sans écran | `minimal` | Pas de veille, watchdog, boot limité |
| `desktop` | Poste de travail | `minimal` | GNOME, multimédia, bureautique |
| `laptop` | Ordinateur portable | `desktop` | Batterie, capteurs, thermald |
| `umi` | Poste accessible | `desktop` | Autologin, uinput, udev Tobii |
| `portable` | Clé USB bootable | `minimal` | Pilotes matériels étendus |
| `gateway` | Passerelle de zone | `server` | Routeur, pare-feu, DNS/DHCP, VPN |
| `hcs` | Coordination du VPN | `server` | Headscale + services partagés |
| `vm` | Machine virtuelle | `server` | Outils invité (VirtualBox/QEMU/Xen) |

## Choisir un profil

```yaml
# etc/config.yaml
hosts:
  - hostname: "poste"
    profile: "desktop"
```

:::caution[Aucun profil ne se met en veille tout seul]
Une machine du parc doit rester joignable&nbsp;: une mise en veille automatique
la sort du réseau, et seule une intervention physique l'en fait revenir. Aucun
profil, portable compris, n'active donc la veille par inactivité, ni sur le
bureau ni sur l'écran de connexion. Pour la rétablir sur une machine
précise&nbsp;:

```yaml
# etc/config.yaml
hosts:
  - hostname: "portable"
    profile: "laptop"
    features: ["auto-suspend"]
```

L'écran s'éteint toujours après un délai d'inactivité, sans suspendre la
machine.
:::

:::tip[Les services sont indépendants du profil]
Un [service](/fr/doc/admin-guide/operate/services/) (Immich, Nextcloud, Forgejo…) se déclare par hôte **quel que soit**
son profil.
:::

:::tip[Le profil `umi` peut demander du matériel]
Un poste piloté au regard suppose un traqueur oculaire et une mise en service
particulière, décrites dans
[Accessibilité](/fr/doc/admin-guide/operate/accessibility/).
:::

Les options de chaque profil sont dans la
