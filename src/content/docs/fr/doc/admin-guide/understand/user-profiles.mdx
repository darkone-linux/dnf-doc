Un **profil d'utilisateur** définit l'environnement [Home Manager](https://github.com/nix-community/home-manager)
d'un compte : applications, bureau, réglages. On le choisit avec `profile:` dans
`etc/config.yaml`. Comme les hôtes, les profils s'héritent.

## Les profils

| Profil | Pour qui | Hérite de |
|---|---|---|
| `minimal` | Base de tout profil | |
| `normal` | Utilisateur standard (bureau) | `minimal` |
| `advanced` | Développeurs, informaticiens | `normal` |
| `umi` | Utilisateur à saisie multimodale (toucher, voix, regard) | `normal` |
| `admin` | Administrateur réseau | `advanced` |
| `nix-admin` | Administrateur du parc (outils Nix) | `admin` |
| `student` | Étudiant | `advanced` |
| `teenager` | Adolescent | `minimal` |
| `gamer` | Joueur | `minimal` |
| `child` | Enfant (Cartable Fantastique, icônes techniques masquées) | `minimal` |
| `baby` | Très jeune enfant | `minimal` |

:::tip[Le profil `umi` et son hôte]
Il prend tout son sens sur un hôte en profil `umi`, qui fournit la session X11
et la prise en charge des périphériques de saisie (traqueur oculaire, injection
d'événements). Sur un autre hôte, le compte garde GNOME et son clavier visuel.
Voir [Accessibilité](/fr/doc/admin-guide/operate/accessibility/).
:::

:::tip[Côté utilisateur]
Une présentation orientée usage figure dans le
[guide de l'utilisateur](/fr/doc/user-guide/understand/profiles/).
:::

## Le bureau GNOME

| Élément | Profils | Comportement |
|---|---|---|
| Paramètres Qt5 / Qt6, manuel NixOS | tous | Icônes masquées (manuel accessible via `nixos-help`) |
| vim, btop, htop | tous | Icônes masquées, programmes toujours lançables depuis un terminal |
| Notification « Soutenir GNOME » | tous | Désactivée |
| Visionneur de documents | tous | Papers, application PDF par défaut (remplace Evince) |
| Visionneur d'images | tous sauf `minimal`, `baby` | Geeqie par défaut |
| Extensions GNOME | non techniques | Icône masquée |
| Trousseau de connexion | non techniques, hôte chiffré | [Sans mot de passe](/fr/doc/admin-guide/operate/users/#un-trousseau-sans-mot-de-passe-) |
| Terminal | non techniques | Console, absente du dash, présente dans la grille d'applications |
| Terminal | techniques | Ghostty, premier favori du dash et Ctrl+Alt+T |
| Dossier « Réseau local » | `nix-admin`, hôte admin | *Doc DNF*, *Premiers pas* (la page d'accueil), *Sources du réseau* (terminal dans `/etc/nixos`) |
| Element (Matrix) | tous sauf `minimal`, `baby` | Lancé masqué si le réseau a Matrix |

:::note[Dash verrouillé]
La liste des favoris (`favorite-apps`) est verrouillée pour tout l'hôte&nbsp;:
Console, terminal des profils non techniques, n'y figure pas.
:::

:::tip[Masquer d'autres icônes]
`darkone.home.gnome.hiddenApps` liste les entrées masquées (identifiants
`.desktop`). La redéfinir dans `usr/users/<login>/default.nix` remplace la
liste par défaut.
:::

:::note[Le dossier « Réseau local »]
Ajouté une seule fois, à la première session : supprimé ou renommé, il ne
revient pas. Pour le recréer, effacer `~/.local/state/dnf/network-folder` puis
rouvrir la session.
:::

:::note[Ghostty et SSH]
Depuis Ghostty, `ssh` installe le terminfo `xterm-ghostty` sur l'hôte distant
à la première connexion (`~/.terminfo`, via `tic`), sinon il se rabat sur
`xterm-256color`. Les hôtes DNF le fournissent déjà à tous les comptes, `root`
compris.
:::

## Le Cartable Fantastique

Le profil `child` ajoute à LibreOffice la barre d'outils du
[Cartable Fantastique](https://www.cartablefantastique.fr/outils-pour-compenser/le-plug-in-libre-office/),
pensée pour les élèves dyspraxiques ou DYS : lire, écrire, calculer, lecture vocale.

| Édition | Pour qui |
|---|---|
| `primaire` | École élémentaire (défaut de `child`) |
| `college` | Collège : langues, chimie, électricité |
| `adaptateur` | Adulte qui adapte des supports |

```nix
# usr/users/<login>/default.nix
darkone.home.office.cartableFantastique = "college"; # null : aucune
```

L'extension s'installe dans le profil LibreOffice du compte, à l'activation
Home Manager (démarrage ou déploiement). La lecture vocale passe par
speech-dispatcher, actif par défaut sur les postes.

:::caution[Retrait manuel]
Repasser l'option à `null` laisse l'extension en place : la retirer via
*Outils → Gestionnaire des extensions*.
:::

## Applications lourdes à la demande

Les profils `admin` et `nix-admin` n'installent ni la création d'images
(GIMP) ni la musique (Audacious). Pour les rendre à un compte&nbsp;:

```nix
# usr/users/<login>/default.nix
darkone.home.imagery.enable = true;
darkone.home.music.enable = true;
```

FileZilla n'est plus installé (SFTP depuis Fichiers ou `sftp`), et KeePassXC
reste le seul gestionnaire KeePass des profils techniques, sans Secrets à côté.

Pour alléger le premier poste, `advanced` et les profils qui en héritent
n'installent ni VS Code (0,3 Gio) ni Slidev (0,4 Gio)&nbsp;: Zed reste l'éditeur
par défaut. Pour les ajouter à un compte, y compris pour retrouver l'ancien
comportement&nbsp;:

```nix
# usr/users/<login>/default.nix
darkone.home.advanced.enableVscode = true;
darkone.home.advanced.enableSlidev = true; # avec son extension VS Code
```

## Affecter un profil

```yaml
# etc/config.yaml
users:
  alice:
    uid: 1000
    name: "Alice"
    profile: "nix-admin"
    groups: ["global"]
```

:::note[Personnaliser]
On crée ou surcharge un profil dans `usr/home/profiles/<nom>/`, un seul compte
dans `usr/users/<login>/default.nix` (options `darkone.home.*`, sans
`lib.mkForce`). Les briques réutilisables sont les [modules Home Manager](/fr/ref/modules/home/).
Un programme d'un profil se retire avec `excludePackages` (modules `games`, `education`).
:::

### Un hash du Cartable Fantastique ne correspond plus

L'éditeur remplace le fichier `.oxt` sans changer d'URL. Recalculer les
`hashes` de `dnf/pkgs/cartable-fantastique/package.nix` avec
`nix store prefetch-file <url>`.
