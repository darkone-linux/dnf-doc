Quand la box tombe, la passerelle bascule seule sur une **liaison de secours**&nbsp;:
un port ethernet libre, le partage de connexion d'un téléphone en wifi… La zone
garde Internet en mode dégradé, puis revient sur la box dès qu'elle répond.

## Principe

Chaque lien vers Internet (la WAN, puis les secours) porte sa propre route par
défaut. La plus basse **métrique** l'emporte.

| Lien | Métrique |
|---|---|
| WAN (la box) | 100 |
| Liaison de secours | 200 + 10 × `priority` (300 par défaut) |
| Lien sans Internet | métrique + 20000 |

Trois situations sont couvertes&nbsp;:

| Situation | Détection | Effet |
|---|---|---|
| Câble débranché, box éteinte, plus de bail DHCP | la route de la WAN disparaît | le noyau prend la route suivante |
| Box allumée mais Internet coupé | la sonde `dnf-uplink-monitor` échoue 3 fois | la WAN passe à 20100, le secours prend le relais |
| Internet revenu sur la box | 6 sondes réussies | retour sur la WAN |

La sonde envoie un ping **par chaque lien** (1.1.1.1 et 9.9.9.9, toutes les 10
secondes). Elle ne dépend pas du DNS&nbsp;: elle vise des adresses IP.

:::note[Veille chaude]
Une liaison de secours reste connectée quand elle est disponible (partage du
téléphone allumé, câble branché). La métrique garde le trafic sur la box tant
qu'elle fonctionne.
:::

## Déclarer une liaison de secours

<Steps>

1. Repérer l'interface sur la passerelle&nbsp;:

   ```sh
   ip -br link
   ```

   Elle doit être libre&nbsp;: ni la WAN, ni un port du LAN, ni la radio d'un
   point d'accès wifi.

2. Déclarer la liaison dans le fichier de l'hôte&nbsp;:

   ```nix
   # usr/machines/gw/configuration.nix
   darkone.host.gateway.backupLinks = {
     phone = {
       type = "wifi";
       interface = "wlp4s0";
     };
     voisin = {
       type = "ethernet";
       interface = "enp3s0";
       priority = 20;
     };
   };
   ```

   | Option | Rôle |
   |---|---|
   | `type` | `ethernet` (client DHCP) ou `wifi` (client WPA2/WPA3) |
   | `interface` | interface qui porte le lien |
   | `priority` | 1 à 99, la plus basse est préférée parmi les secours |

3. Pour un lien wifi, saisir le SSID et la passphrase dans sops avec `just sops`&nbsp;:

   ```yaml
   # usr/secrets/secrets.yaml
   backup-link:
     phone:
       ssid: "Partage du téléphone"
       psk: "passphrase-du-partage"
   ```

   Le SSID et la passphrase ne passent jamais par le store Nix.

4. Déployer&nbsp;:

   ```sh
   just apply gw
   ```

</Steps>

## Vérifier

```sh
networkctl list                       # le lien est « routable » quand il est actif
ip -4 route show default              # la première ligne est le lien utilisé
journalctl -u dnf-uplink-monitor -f   # bascules, en direct
```

Avec la box en panne et le téléphone en partage de connexion&nbsp;:

```
default via 192.168.1.254 dev enp1s0 proto dhcp src 192.168.1.10 metric 20100
default via 192.168.43.1 dev wlp4s0 proto dhcp src 192.168.43.20 metric 300
```

## Régler la sonde

| Option | Défaut | Rôle |
|---|---|---|
| `darkone.host.gateway.linkCheck.targets` | `1.1.1.1`, `9.9.9.9` | adresses pingées, une réponse suffit |
| `darkone.host.gateway.linkCheck.interval` | 10 | secondes entre deux tours |
| `darkone.host.gateway.linkCheck.failAfter` | 3 | échecs avant de pénaliser un lien |
| `darkone.host.gateway.linkCheck.recoverAfter` | 6 | succès avant de le rétablir |

## Supervision

La sonde publie deux métriques pour Prometheus&nbsp;:

| Métrique | Valeur |
|---|---|
| `dnf_gateway_link_up` | 1 si le lien a une route et atteint Internet |
| `dnf_gateway_link_active` | 1 sur le lien qui porte la route par défaut |

L'alerte `GatewayOnBackupLink` (avertissement) se déclenche après 2 minutes sur
une liaison de secours.

## Limites à connaître

:::caution[Une radio par rôle]
Une carte wifi ne peut pas être à la fois point d'accès et client. Il faut une
seconde carte (ou un dongle USB) pour une liaison de secours wifi.
:::

:::caution[Liaison facturée au volume]
Sur un partage de téléphone ou une 4G, toute la zone consomme des données&nbsp;:
mises à jour, sauvegardes, caches. Surveiller la consommation.
:::

| Limite | Détail |
|---|---|
| Flux coupés à la bascule | les connexions en cours repartent par le nouveau lien (appel ou téléchargement à relancer) |
| Sous-réseau en conflit | un lien qui distribue des adresses du réseau de la zone (ex. `10.0.0.0/16`) casse le routage ; un partage de téléphone utilise un petit réseau distinct (`/24`), sans conflit en pratique |
| SSID et passphrase | sans guillemet double (`"`) |
| Déverrouillage LUKS à distance | par la WAN ou le LAN seulement |
| Liaisons retirées | une pénalité en cours reste jusqu'au redémarrage&nbsp;: supprimer `/run/systemd/network/*.network.d/90-dnf-penalty.conf`, puis `networkctl reload` |
