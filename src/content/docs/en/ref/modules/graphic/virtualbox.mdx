## Options

* **enable** `bool` Pre-configured virtualbox installation
* **enableExtensionPack** `bool` Enable extension pack (causes recompilations)

```nix
darkone.graphic.virtualbox = {
  enable = false;
  enableExtensionPack = false;
};
```
