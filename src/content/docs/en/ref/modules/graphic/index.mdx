**A GUI application module** installs graphical applications and their configuration optimized for DNF.

| Module | Role |
|---|---|
| [`gnome`](/en/ref/modules/graphic/gnome/) | Pre-configured gnome environment with dependences. |
| [`qemu`](/en/ref/modules/graphic/qemu/) | QEMU test VMs bridged on the DNF LAN |
| [`remote-desktop`](/en/ref/modules/graphic/remote-desktop/) | Admin remote desktop: attach to an open graphical session, or open one, over RDP. |
| [`supertuxkart`](/en/ref/modules/graphic/supertuxkart/) | SuperTuxKart with configurations to play in local network. |
| [`virt-manager`](/en/ref/modules/graphic/virt-manager/) | Virt manager + viewer with spice, win-virtio and ovmf. |
| [`virtualbox`](/en/ref/modules/graphic/virtualbox/) | Virtualbox host installation. |
