**A mixin module** defines a collection of standard modules with a consistent common configuration.

| Module | Role |
|---|---|
| [`host.ai-space`](/en/ref/modules/mixin/host-ai-space/) | AI space: headless host running the agents of one space (owner + members). |
| [`host.desktop`](/en/ref/modules/mixin/host-desktop/) | A full desktop configuration with gnome, multimedia and office tools. |
| [`host.gateway`](/en/ref/modules/mixin/host-gateway/) | The main gateway / router of a local network zone. |
| [`host.hcs`](/en/ref/modules/mixin/host-hcs/) | The main headscale coordination server. |
| [`host.laptop`](/en/ref/modules/mixin/host-laptop/) | Desktop config + laptop specific tools &amp; configuration. |
| [`host.minimal`](/en/ref/modules/mixin/host-minimal/) | Every host configuration is based on this minimal config. |
| [`host.portable`](/en/ref/modules/mixin/host-portable/) | Portable configuration for a bootable USB drive containing a NixOS machine from the local network. |
| [`host.server`](/en/ref/modules/mixin/host-server/) | Improved configuration for servers (minimal, no sleep, watchdog...). |
| [`host.umi`](/en/ref/modules/mixin/host-umi/) | Host profile: UMI (Unified Multimodal Input) workstation, usable without keyboard/mouse. |
| [`host.vm`](/en/ref/modules/mixin/host-vm/) | Virtual machines guest tools. |
| [`profile.advanced`](/en/ref/modules/mixin/profile-advanced/) | Profile for advanced users (computer scientists, developers, admins). |
