Virtual machines guest tools.

## Options

* **enableVirtualbox** `bool` Virtualbox client
* **enableQemu** `bool` Qemu/KVM client
* **enableXen** `bool` Xen client

```nix
darkone.host.vm = {
  enableVirtualbox = false;
  enableQemu = false;
  enableXen = false;
};
```
