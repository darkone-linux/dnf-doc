A pre-configured git environment.

:::tip[Git shortcuts]
- `git hdf` (history diff): select a commit to display diff.
- `git tree`: history tree.
- `git tre`: history with files.
- `git treee`: history with commit messages.
- `git hist`: tree alternative.
:::
