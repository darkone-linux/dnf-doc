**A CLI application module** installs terminal applications and their configuration optimized for DNF.

| Module | Role |
|---|---|
| [`git`](/en/ref/modules/console/git/) | A pre-configured git environment. |
| [`zsh`](/en/ref/modules/console/zsh/) | A full zsh installation with aliases, bindkeys and optimized prompt. |
