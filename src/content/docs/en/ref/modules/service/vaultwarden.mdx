A full-configured vaultwarden server.

:::note[Admin panel]
`/admin` answers the LAN and the tailnet only: zones and tailnet resolve the
service to the HCS tailnet IP. Bitwarden clients (web, extension, mobile)
stay public.
:::

{/* t:p 67b72ef9ddf257f49848ee69490eb082210ed7781aabf856ca4d9c4cc109dce2 */}
## Options

* **enable** `bool` Enable local Vaultwarden service
* **enableSmtp** `bool` Enable SMTP to send emails (recommended, needs `network.smtp`)

```nix
darkone.service.vaultwarden = {
  enable = false;
  enableSmtp = true;
};
```
