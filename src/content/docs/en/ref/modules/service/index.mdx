**A service module** provides a ready-to-use service (daemon).

| Module | Role |
|---|---|
| [`adguardhome`](/en/ref/modules/service/adguardhome/) | Full-configured AdGuard Home for local gateway / router. |
| [`ai`](/en/ref/modules/service/ai/) | Local Artifical Intelligence (open-webui + ollama + llms). |
| [`audio`](/en/ref/modules/service/audio/) | Audio services: alsa, pulse (not jack for the moment). Automatically adds users to the `audio` group when enabled. |
| [`dnsmasq`](/en/ref/modules/service/dnsmasq/) | Pre-configured dnsmasq for local gateway / router. |
| [`docs`](/en/ref/modules/service/docs/) | A full-configured LaSuite Docs module. |
| [`element`](/en/ref/modules/service/element/) | Element web client for local matrix service. |
| [`fail2ban`](/en/ref/modules/service/fail2ban/) | Fail2ban DNF specific module. |
| [`forgejo`](/en/ref/modules/service/forgejo/) | A full-configured forgejo git forge. |
| [`garage`](/en/ref/modules/service/garage/) | A full-configured local Garage S3 service. |
| [`geneweb`](/en/ref/modules/service/geneweb/) | GeneWeb — Powerful Genealogy Service. |
| [`harmonia`](/en/ref/modules/service/harmonia/) | Harmonia: local Nix binary cache server (serves this host's /nix/store). |
| [`headscale`](/en/ref/modules/service/headscale/) | A full-configured headscale service for HCS. |
| [`home-assistant`](/en/ref/modules/service/home-assistant/) | A Home Assistant with some plugins (wip). |
| [`homepage`](/en/ref/modules/service/homepage/) | Dynamically configured homepage dashboard for your local network. |
| [`idm`](/en/ref/modules/service/idm/) | Kanidm (identity manager) DNF Service. |
| [`immich`](/en/ref/modules/service/immich/) | Immich (photo management) full-configured service. |
| [`jellyfin`](/en/ref/modules/service/jellyfin/) | A full-configured jellyfin server. |
| [`jitsi-meet`](/en/ref/modules/service/jitsi-meet/) | A full-configured jitsi-meet service. |
| [`loki`](/en/ref/modules/service/loki/) | Loki + Alloy, http stats with grafana. |
| [`matrix`](/en/ref/modules/service/matrix/) | DNF matrix (synapse) homeserver. |
| [`matrix-admin`](/en/ref/modules/service/matrix-admin/) | Matrix administration UI (Ketesa, formerly synapse-admin) for the local server. |
| [`mealie`](/en/ref/modules/service/mealie/) | Mealie Recipe Management |
| [`minio`](/en/ref/modules/service/minio/) | A full-configured local MinIO S3 service. (wip) |
| [`monitoring`](/en/ref/modules/service/monitoring/) | Supervision module: Grafana dashboards + per-node exporter. |
| [`nextcloud`](/en/ref/modules/service/nextcloud/) | Nextcloud full-configured service. |
| [`nfs`](/en/ref/modules/service/nfs/) | NFS server + client for home shares. |
| [`nix-cache`](/en/ref/modules/service/nix-cache/) | Per-zone Nix binary-cache proxy (nginx `proxy_cache`). |
| [`openclaw`](/en/ref/modules/service/openclaw/) | OpenClaw assistant of an AI space (gateway + control UI, behind the zone SSO). |
| [`outline`](/en/ref/modules/service/outline/) | A full-configured outline wiki. |
| [`oxicloud`](/en/ref/modules/service/oxicloud/) | OxiCloud — Fast Sovereign Cloud (file storage, WebDAV, CalDAV &amp; CardDAV). |
| [`postfix`](/en/ref/modules/service/postfix/) | Postfix SMTP Relay. |
| [`printing`](/en/ref/modules/service/printing/) | Printers and scanners. |
| [`prometheus`](/en/ref/modules/service/prometheus/) | Prometheus monitoring server with declarative Alertmanager escalation. |
| [`restic`](/en/ref/modules/service/restic/) | Restic backup module: REST server + per-host backup targets. |
| [`searx`](/en/ref/modules/service/searx/) | A full-configured hardened search engine. |
| [`stk`](/en/ref/modules/service/stk/) | SuperTuxKart shared tracks, served over NFS. |
| [`tailscale`](/en/ref/modules/service/tailscale/) | Tailscale client of the DNF tailnet (headscale on the HCS). |
| [`turn`](/en/ref/modules/service/turn/) | Coturn server (matrix). |
| [`vaultwarden`](/en/ref/modules/service/vaultwarden/) | A full-configured vaultwarden server. |
