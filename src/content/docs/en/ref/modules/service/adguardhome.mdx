Full-configured AdGuard Home for local gateway / router.

:::note
This configuration reads the `network` conf in `config.yaml` file.
It uses the [DNF dnsmasq module](/en/ref/modules/service/dnsmasq/) as upstream DNS and DHCP.
:::

## Options

* **enable** `bool` Enable local adguardhome service

```nix
darkone.service.adguardhome.enable = false;
```

Source: [`modules/service/adguardhome.nix`](https://github.com/darkone-linux/darkone-nixos-framework/blob/main/modules/service/adguardhome.nix)
