**A home manager module** works with [home manager](https://github.com/nix-community/home-manager) profiles.

| Module | Role |
|---|---|
| [`advanced`](/en/ref/modules/home/advanced/) | Home profile for advanced users (computer scientists, developers, admins). |
| [`ai`](/en/ref/modules/home/ai/) | AI coding tools and supporting utilities. |
| [`ai-space`](/en/ref/modules/home/ai-space/) | Agent tools of an AI space in a member's home: Claude Code, Codex, OpenCode, MCP, skills. |
| [`audio`](/en/ref/modules/home/audio/) | Audio tools and effects. |
| [`education`](/en/ref/modules/home/education/) | Several graphical education packages. |
| [`games`](/en/ref/modules/home/games/) | Several graphical game packages. |
| [`gnome`](/en/ref/modules/home/gnome/) | Gnome tweaks for home-manager. |
| [`imagery`](/en/ref/modules/home/imagery/) | Image processing software. |
| [`mime`](/en/ref/modules/home/mime/) | Default applications (`xdg.mimeApps`) for documents, images, audio, video. |
| [`music`](/en/ref/modules/home/music/) | Graphical music and sound creation apps. |
| [`office`](/en/ref/modules/home/office/) | Office desktop: browsers, office suite, communication, cloud and PDF tools. |
| [`umi`](/en/ref/modules/home/umi/) | Unified Multimodal Input (UMI) |
| [`video`](/en/ref/modules/home/video/) | Video tools and applications. |
