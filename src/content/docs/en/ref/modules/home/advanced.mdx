Home profile for advanced users (computer scientists, developers, admins).

:::note[SSH keys from Vaultwarden]
`enableVaultwardenSsh` turns `rbw` into the SSH agent: private keys stay in
the user's vault (end-to-end encrypted), never in clear on disk nor in sops.
The user runs `rbw unlock` once per session.
:::

:::note[Local network folder]
A nix-admin on the admin host gets a "Local network" folder in the app grid
(`advanced/network-folder.nix`): DNF Doc, Onboarding (the welcome page) and
Network Sources (a terminal in `/etc/nixos`). Added once per user, at login.
:::

:::note[One clipboard in the terminal]
Ghostty, tmux, zellij and vim share CLIPBOARD (GNOME's Ctrl+C / Ctrl+V):
selecting copies; middle-click, right-click and Ctrl+V paste. PRIMARY is
never pasted. Shift + mouse bypasses an app that grabs the mouse.
:::

## Options

* **enable** `bool` Enable advanced user features
* **enableTools** `bool` Various tools for advanced users
* **enablePhoneTools** `bool` Smartphone tools (scrcpy)
* **enableAdmin** `bool` Enable administrator features (network, os tools)
* **enableNixAdmin** `bool` Enable nix administration features
* **enableDnfDeveloper** `bool` Enable all tools for DNF Codev Developer
* **enableDeveloper** `bool` Enable tools for developer
* **enableVscode** `bool` VS Code. Opt-in: ~0.3 GiB to download, Zed is the default editor
* **enableSlidev** `bool` Slidev presentations (`slidev-cli`, plus its VS Code extension when
  `enableVscode`). Opt-in: ~0.4 GiB to download
* **enableEssentials** `bool` Frequently used tools
* **enableVaultwardenSsh** `bool` SSH agent backed by the user's Vaultwarden vault (rbw). Do not enable on
  a host reached with `ssh -A`: the local agent would mask the forwarded one

```nix
darkone.home.advanced = {
  enable = false;
  enableTools = false;
  enablePhoneTools = false;
  enableAdmin = false;
  enableNixAdmin = false;
  enableDnfDeveloper = false;
  enableDeveloper = true;
  enableVscode = false;
  enableSlidev = false;
  enableEssentials = true;
  enableVaultwardenSsh = false;
};
```
