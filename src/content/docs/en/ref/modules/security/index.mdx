**A security module** hardens the system, its programs and functionalities.

| Module | Role |
|---|---|
| [`complement`](/en/ref/modules/security/complement/) | Cross-cutting complementary measures — Annex A (C1–C12). (wip) |
| [`filesystem`](/en/ref/modules/security/filesystem/) | Partitioning, file tree, and file permissions (R28–R29, R50–R57). (wip) |
| [`integrity`](/en/ref/modules/security/integrity/) | Filesystem integrity — HIDS (R76–R77). (wip) |
| [`journaling`](/en/ref/modules/security/journaling/) | Logging and auditd (R71–R73). (wip) |
| [`kernel-build`](/en/ref/modules/security/kernel-build/) | Static kernel configuration — requires recompilation (R15–R27). (wip) |
| [`kernel-params`](/en/ref/modules/security/kernel-params/) | Dynamic kernel configuration: boot parameters and sysctls (R8–R14). (wip) |
| [`mac`](/en/ref/modules/security/mac/) | Mandatory Access Control — MAC (R37, R45–R49). (wip) |
| [`mta`](/en/ref/modules/security/mta/) | Local mail handling (R74–R75). (wip) |
| [`network`](/en/ref/modules/security/network/) | Network services — isolation and supervision (R78–R80). (wip) |
| [`nss`](/en/ref/modules/security/nss/) | NSS — Remote user databases (R69–R70). (wip) |
| [`packages`](/en/ref/modules/security/packages/) | Package management and updates (R58–R61). (wip) |
| [`pam`](/en/ref/modules/security/pam/) | PAM — Authentication and password storage (R67–R68). (wip) |
| [`preboot`](/en/ref/modules/security/preboot/) | Hardware configuration and secure boot (R1–R7). (wip) |
| [`services`](/en/ref/modules/security/services/) | Hardening of systemd services (R62–R66). (wip) |
| [`sudo`](/en/ref/modules/security/sudo/) | sudo hardening (R38–R44). (wip) |
| [`users`](/en/ref/modules/security/users/) | User accounts and authentication (R30–R36). (wip) |
