**An administration module** deals with system-specific functionalities for administrators.

| Module | Role |
|---|---|
| [`fleet-update`](/en/ref/modules/admin/fleet-update/) | Fleet update tool (`fleet-update`) and its unattended daily run. |
| [`locate`](/en/ref/modules/admin/locate/) | Fleet host locator (`dnf-locate`): ssh finds a host wherever it is plugged. |
| [`nix`](/en/ref/modules/admin/nix/) | NixOS configuration for the local LAN administrator computer. |
| [`welcome`](/en/ref/modules/admin/welcome/) | First-boot welcome page of the admin host installed by `darkone new`. |
