**A users management module** manages user-related processing or special user settings.

| Module | Role |
|---|---|
| [`build`](/en/ref/modules/user/build/) | Build users NixOS (not home-manager) configuration. |
| [`root`](/en/ref/modules/user/root/) | Root user specific settings. |
