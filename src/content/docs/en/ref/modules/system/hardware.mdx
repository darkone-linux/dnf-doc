Hardware configuration improvements.

Every firmware is loaded (`hardware.enableAllFirmware`), except on a virtual
machine: `just detect-hw` probes it (`systemd-detect-virt --vm`) and sets
`darkone.system.hardware.virtual` in `hardware/detected-hardware.nix`. A
guest also lets Zed run on its emulated GPU (`ZED_ALLOW_EMULATED_GPU`).

{/* t:p 350a8bfe11b9f68f8333463a4b6d32ab7c8b432b1a82ea1836c9c6a9e354bd19 */}
## Options

* **enable** `bool` Enable hardware optimisations
* **enableIntel** `bool` Enable intel microcode updates
* **enableAmd** `bool` Enable amd microcode updates
* **virtual** `bool` Virtual machine, no firmware loaded. Set by `just detect-hw`

```nix
darkone.system.hardware = {
  enable = false;
  enableIntel = false;
  enableAmd = false;
  virtual = false;
};
```
