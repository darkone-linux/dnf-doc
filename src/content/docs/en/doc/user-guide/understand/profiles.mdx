### User profiles

Each user is linked to a "profile" (your choice, interchangeable), which determines:

* The programs and configurations of [workstations](/en/doc/user-guide/understand/linux-workstations/) (education, office, games...).
* The access to and configuration of [online services](/en/doc/user-guide/understand/services/).

| **Profile** | **Description** |
|----|----|
| ⚪ minimal | The bare minimum of programs and tools. |
| 🔵 normal | For non-technical office user → the essentials. |
| 🟣 advanced | For IT professionals → a nice shell and development tools. |
| 🔴 admin | Account dedicated to network and system administrators (expert). |
| 🎨 creator | For multimedia creators → video, music, photo, image. |
| 📘 student | For studies → taking notes, getting organized, studying. |
| 🎮 gamer | Plenty of native games under Linux. |
| 🎒 teen | Fun and educational apps to get started with the internet. |
| 🧩 child | Educational software to learn, without internet access. |
| 🧸 baby | Very stripped-down system → learn the mouse, numbers, shapes, etc. |
| 👁️ umi | Session controlled by gaze, voice, touch, without keyboard or mouse. |
