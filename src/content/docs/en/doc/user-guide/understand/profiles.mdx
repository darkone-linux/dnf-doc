### User profiles

Each user is linked to a "profile" (optional and interchangeable), which determines:

* The programs and configurations [of workstations](/en/doc/user-guide/understand/linux-workstations/) (education, office suite, games…).
* The access and configuration of [online services](/en/doc/user-guide/understand/services/).

| **Profile** | **Description** |
|----|----|
| ⚪ minimal | The bare minimum of programs and tools. |
| 🔵 normal | For non-technical office users → the essentials. |
| 🟣 advanced | For IT professionals → a nice shell and development tools. |
| 🔴 admin | Dedicated account for network and system administrators (expert). |
| 🎨 creator | For multimedia creators → video, music, photo, graphics. |
| 📘 student | For studying → taking notes, getting organized, learning. |
| 🎮 gamer | Plenty of native Linux games. |
| 🎒 teen | Fun and educational apps to get started with the internet. |
| 🧩 child | Educational software for learning, no internet access required. |
| 🧸 baby | Very streamlined system → learn the mouse, numbers, shapes, etc. |
| 🌳 umi | Accessibility → workstation controlled by touch, voice, and eye tracking. |
