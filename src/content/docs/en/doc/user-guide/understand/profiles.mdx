### User profiles

Each user is linked to a "profile" (freely chosen and interchangeable), which determines:

* The programs and configurations [of the workstations](/en/doc/user-guide/understand/linux-workstations/) (education, office, games…).
* Access to and configuration of [online services](/en/doc/user-guide/understand/services/).

| **Profile** | **Description** |
|----|----|
| ⚪ minimal | The bare minimum of programs and tools. |
| 🔵 normal | For non-technical office users → the essentials. |
| 🟣 advanced | For IT professionals → a nice shell and development tools. |
| 🔴 admin | Account dedicated to network and system administrators (expert). |
| 🎨 creator | For multimedia creators → video, music, photo, image. |
| 📘 student | For studying → taking notes, getting organized, studying. |
| 🎮 gamer | Plenty of native games on Linux. |
| 🎒 teen | Educational and fun apps to get started with the internet. |
| 🧩 child | Educational software and [Cartable Fantastique](https://www.cartablefantastique.fr/) in LibreOffice, without internet access. |
| 🧸 baby | A very stripped-down system → learning the mouse, numbers, shapes, etc. |
| 🌳 umi | Accessibility → a workstation driven by touch, voice and gaze. |
