An **AI space** is a DNF host with the `ai-space` profile, generally a
[microVM guest](/en/doc/admin-guide/operate/microvm/). It hosts an
[OpenClaw](https://openclaw.ai) assistant reserved for its members, with its own
secrets and its own data.

:::caution[In progress]
Web access and SSO in place. The Matrix channel, the tools (Claude Code, Codex)
and the MCPs are coming in the next releases.
:::

## Create a space

<Steps>

1. **Declare the host and its members**

   The host's `users` are its members: DNF creates for them the Kanidm group
   `space-<host>`.

   ```yaml
   # etc/config.yaml
   - hostname: "ia-pro"
     zone: "lan:1.40"
     profile: "ai-space"
     features: ["microvm-guest:hyperviseur"]
     users: ["alice", "bob"]
     services:
       openclaw: {}
   ```

2. **Initialize its secrets**

   `just space-init ia-pro` (see
   [Isolated hosts](/en/doc/admin-guide/operate/secrets/)).

3. **Deploy**

   The hypervisor, the zone gateway (vhost, DNS) and the HCS (Kanidm
   group): `just apply hyperviseur,gw,hcs`.

4. **Connect an AI provider**

   Once per space, from the host (`just enter ia-pro`):

   ```bash
   sudo -u openclaw openclaw models auth login --provider openai-codex
   ```

   The connection stays in `/var/lib/openclaw`, persistent.

</Steps>

## Member accounts

Each member has a Linux account on the space, streamlined:

| Item | On the space |
|---|---|
| Home Manager profile | `space-member` (zsh, git, vim, tmux), instead of their own |
| Customizations | `usr/users/<login>/space.nix` (all their spaces), then `usr/users/<login>/spaces/<host>.nix` (this space), if they exist |
| `usr/users/<login>/default.nix` | Ignored: reserved for their workstations |
| Rights | No group (no `sudo`), whatever their profile |

Administration of the space goes through the `nix` account
(`just enter <host>`).

:::tip[Customize a space]
These files are ordinary Home Manager modules: packages, aliases, git
configuration, other imported modules.
:::

## Access

| Item | Rule |
|---|---|
| Address | `https://openclaw.<zone>.<domaine>` |
| Login | Kanidm SSO, reserved to the group `space-<host>` |
| Device | Paired on first visit, without administration rights |
| Administration | Command line on the host (`openclaw …`) |
| Assistant port | Reachable from the zone gateway only |

:::note[One subscription per person]
A personal subscription (ChatGPT, Claude) shared by several members goes
against the terms of use: a team space takes a team plan or API keys.
:::
