A **user profile** defines the [Home Manager](https://github.com/nix-community/home-manager)
environment of an account: applications, desktop, settings. It is chosen via `profile:` in
`etc/config.yaml`. Like hosts, profiles can inherit from one another.

## Profiles

| Profile | For whom | Inherits from |
|---|---|---|
| `minimal` | Base of every profile | |
| `normal` | Standard user (desktop) | `minimal` |
| `advanced` | Developers, IT professionals | `normal` |
| `umi` | Multimodal input user (touch, voice, gaze) | `normal` |
| `admin` | Network administrator | `advanced` |
| `nix-admin` | Fleet administrator (Nix tools) | `admin` |
| `student` | Student | `advanced` |
| `teenager` | Teenager | `minimal` |
| `gamer` | Gamer | `minimal` |
| `child` | Child (Cartable Fantastique, technical icons hidden) | `minimal` |
| `baby` | Very young child | `minimal` |

:::tip[The `umi` profile and its host]
It makes full sense on a host in the `umi` profile, which provides the X11
session and input device support (eye tracker, event injection). On another
host, the account keeps GNOME and its on-screen keyboard.
See [Accessibility](/en/doc/admin-guide/operate/accessibility/).
:::

:::tip[From the user's side]
A usage-oriented presentation is available in the
[user guide](/en/doc/user-guide/understand/profiles/).
:::

## The GNOME desktop

| Element | Profiles | Behavior |
|---|---|---|
| Qt5 / Qt6 settings, NixOS manual | all | Icons hidden (manual accessible via `nixos-help`) |
| vim, btop, htop | all | Icons hidden, programs still launchable from a terminal |
| "Support GNOME" notification | all | Disabled |
| Document viewer | all | Papers, default PDF application (replaces Evince) |
| Image viewer | all | Geeqie by default, if the `imagery` module is active |
| GNOME extensions | non-technical | Icon hidden |
| Terminal | non-technical | Console, absent from the dash, present in the applications grid |
| Terminal | technical | Ghostty, first dash favorite and Ctrl+Alt+T |
| "Local Network" folder | `nix-admin`, admin host | DNF Doc, Onboarding (the home page), Network Sources (terminal in `/etc/nixos`) |
| Element (Matrix) | all except `minimal`, `baby` | Launched hidden if the network has Matrix |

:::note[Dash locked]
The favorites list (`favorite-apps`) is locked for the entire host: Console,
the terminal of non-technical profiles, is not listed there.
:::

:::tip[Hide other icons]
`darkone.home.gnome.hiddenApps` lists the hidden entries (`.desktop`
identifiers). Redefining it in `usr/users/<login>/default.nix` replaces the
default list.
:::

:::note[The "Local Network" folder]
Added only once, at the first session: once deleted or renamed, it does not
come back. To recreate it, delete `~/.local/state/dnf/network-folder` then log
back in.
:::

:::note[Ghostty and SSH]
From Ghostty, `ssh` installs the `xterm-ghostty` terminfo on the remote host
at first connection (`~/.terminfo`, via `tic`), otherwise it falls back to
`xterm-256color`. DNF hosts already provide it to all accounts, `root`
included.
:::

## Cartable Fantastique

The `child` profile adds to LibreOffice the toolbar from
[Cartable Fantastique](https://www.cartablefantastique.fr/outils-pour-compenser/le-plug-in-libre-office/),
designed for students with dyspraxia or DYS: read, write, calculate, text to speech.

| Edition | For whom |
|---|---|
| `primaire` | Elementary school (default of `child`) |
| `college` | Middle school: languages, chemistry, electricity |
| `adaptateur` | Adult adapting learning materials |

```nix
# usr/users/<login>/default.nix
darkone.home.office.cartableFantastique = "college"; # null : aucune
```

The extension is installed in the account's LibreOffice profile when Home
Manager activates (startup or deployment). Text to speech goes through
speech-dispatcher, active by default on workstations.

:::caution[Manual removal]
Setting the option back to `null` leaves the extension in place: remove it via
*Tools → Extension Manager*.
:::

## Heavy applications on demand

The `admin` and `nix-admin` profiles install neither image creation (GIMP,
Geeqie) nor music (Audacious). To get them back for an account:

```nix
# usr/users/<login>/default.nix
darkone.home.imagery.enable = true;
darkone.home.music.enable = true;
```

FileZilla is no longer installed (SFTP from Files or `sftp`), and KeePassXC
remains the only KeePass manager of technical profiles, with no Secrets
alongside.

To lighten the first machine, `advanced` and the profiles inheriting from it
install neither VS Code (0.3 GiB) nor Slidev (0.4 GiB): Zed remains the
default editor. To add them to an account, including to restore the previous
behavior:

```nix
# usr/users/<login>/default.nix
darkone.home.advanced.enableVscode = true;
darkone.home.advanced.enableSlidev = true; # avec son extension VS Code
```

## Assigning a profile

```yaml
# etc/config.yaml
users:
  alice:
    uid: 1000
    name: "Alice"
    profile: "nix-admin"
    groups: ["global"]
```

:::note[Customizing]
Create or override a profile in `usr/home/profiles/<nom>/`, a single account
in `usr/users/<login>/default.nix` (`darkone.home.*` options, without
`lib.mkForce`). The reusable building blocks are the
[Home Manager modules](/en/ref/modules/home/).
A program from a profile is removed with `excludePackages` (`games`,
`education` modules).
:::

### A Cartable Fantastique hash no longer matches

The publisher replaces the `.oxt` file without changing the URL. Recalculate the
`hashes` of `dnf/pkgs/cartable-fantastique/package.nix` with
`nix store prefetch-file <url>`.
