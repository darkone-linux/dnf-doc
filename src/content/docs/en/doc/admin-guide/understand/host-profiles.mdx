A **host profile** is a template that defines the role of a machine. It is
chosen with `profile:` in `etc/config.yaml`. Profiles are inherited: each
starts from another and adds its specifics.

{/* t:p 703d240860edd11b73aeaf7e73be9683cd351d5afc1cec7c7e65b950debcf62d */}

## The profiles

| Profile | For what | Inherits from | Provides |
|---|---|---|---|
| `minimal` | Base of every host | | Hardware, firewall, i18n, zsh, sudo |
| `server` | Headless server | `minimal` | No suspend, watchdog, limited boot |
| `desktop` | Workstation | `minimal` | GNOME, multimedia, office suite |
| `laptop` | Laptop | `desktop` | Battery, sensors, thermald |
| `umi` | Accessible workstation | `desktop` | Autologin, uinput, Tobii udev |
| `portable` | Bootable USB drive | `minimal` | Extended hardware drivers |
| `gateway` | Zone gateway | `server` | Router, firewall, DNS/DHCP, VPN |
| `hcs` | VPN coordination | `server` | Headscale + shared services |
| `vm` | Virtual machine | `server` | Guest tools (VirtualBox/QEMU/Xen) |

## Choosing a profile

```yaml
# etc/config.yaml
hosts:
  - hostname: "poste"
    profile: "desktop"
```

:::caution[No profile puts itself to sleep on its own]
A fleet machine must stay reachable&nbsp;: automatic sleep takes it off the
network, and only physical intervention brings it back. No profile, portable
included, therefore enables sleep by inactivity, neither on the desktop nor on
the login screen. To restore it on a specific machine&nbsp;:

```yaml
# etc/config.yaml
hosts:
  - hostname: "portable"
    profile: "laptop"
    features: ["auto-suspend"]
```

The screen always turns off after an inactivity delay, without suspending the
machine.
:::

:::tip[Services are independent of the profile]
A [service](/en/doc/admin-guide/operate/services/) (Immich, Nextcloud, Forgejo…) is declared per host **regardless of**
its profile.
:::

:::tip[The `umi` profile may require hardware]
A UMI (*Unified Multimodal Input*) station is driven by combining touch, voice
and gaze. Each input method requires its own hardware (touchscreen,
microphone, eye tracker) and a specific setup, described in
[Accessibility](/en/doc/admin-guide/operate/accessibility/).
:::
