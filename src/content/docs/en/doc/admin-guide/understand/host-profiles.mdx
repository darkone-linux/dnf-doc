A **host profile** is a template that defines the role of a machine. It is
chosen with `profile:` in `etc/config.yaml`. Profiles are inherited: each
starts from another and adds its specifics.

{/* t:p aee29ff52873c91f1c0c64c2dafd1631587e473ffd84730e563a3635c4e2f75b */}

## Profiles

| Profile | Purpose | Inherits from | Provides |
|---|---|---|---|
| `minimal` | Base for every host | | Hardware, firewall, i18n, zsh, sudo |
| `server` | Headless server | `minimal` | No sleep, watchdog, limited boot |
| `desktop` | Workstation | `minimal` | GNOME, multimedia, office suite |
| `laptop` | Laptop | `desktop` | Battery/sleep, sensors, thermald |
| `umi` | Gaze-controlled workstation | `desktop` | X11 Cinnamon session, autologin, uinput, Tobii udev |
| `portable` | Bootable USB drive | `minimal` | Extended hardware drivers |
| `gateway` | Zone gateway | `server` | Router, firewall, DNS/DHCP, VPN |
| `hcs` | VPN coordination | `server` | Headscale + shared services |
| `vm` | Virtual machine | `server` | Guest tools (VirtualBox/QEMU/Xen) |

## Choosing a profile

```yaml
# etc/config.yaml
hosts:
  - hostname: "poste"
    profile: "desktop"
```

:::tip[Services are independent of the profile]
A service (Immich, Nextcloud, Forgejo…) is declared per host **regardless of**
its profile. See [Services](/en/doc/admin-guide/operate/services/).
:::

:::tip[The `umi` profile requires specific hardware]
A gaze-controlled workstation requires an eye tracker and a specific setup,
described in
[Accessibility](/en/doc/admin-guide/operate/accessibility/).
:::

:::note[Full reference]
Each profile's options are listed in the
[module reference](/en/ref/modules/mixin/).
:::
