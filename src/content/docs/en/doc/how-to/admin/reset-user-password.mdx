A user has lost access to their account. Before taking action, identify **which**
of the three passwords is involved: they are independent.

{/* t:p ae90d566c2871e797c39bb6e33a3100a567665d05f8e1144aaa74b9e6fd0d00d */}
## Three distinct passwords

| Password | Used for | Where to reset it |
|---|---|---|
| **Identity** (Kanidm) | Logging into services (SSO) | Kanidm token (below) |
| **Vault** (Vaultwarden) | Unlocking the password manager | Vaultwarden invitation |
| **Session** (NixOS) | Opening a session on a workstation | `just passwd` (below) |

{/* t:p 02ae423fa43bbfaa02c352b026830679ee246471f5bca95df285f80bfdeff87f */}
## Identity and password vault

<Steps>

1. **Password vault (Vaultwarden)** : resend an invitation from the administration interface ; the user sets a new master password via email.
2. **Identity (Kanidm)** : regenerate a reset token on the coordination server :

   ```bash
   just enter hcs
   kanidm person credential create-reset-token <login> --name idm_admin
   ```

3. Share the link or QR code with the user, who recreates their recovery key and password.

</Steps>

:::tip[Details]
The full account creation procedure is described in the
[admin guide](/en/doc/admin-guide/operate/sso/#create-a-user-account).
:::

## Session password

The login password on a workstation is managed in the
[secrets](/en/doc/admin-guide/operate/secrets/), not in Kanidm:

<Steps>

1. **Set the fingerprint**

   ```bash
   just passwd <login>
   ```

2. **Validate and deploy**

   ```bash
   just commit "user(passwd): <login>"
   just apply @user-<login>
   ```

</Steps>

:::note[Default password]
`just passwd-default` stores the reference password of the fleet, without
configuring any account: a new account only opens a session after
`just passwd <login>`. See [Users](/en/doc/admin-guide/operate/users/).
:::

:::tip[YubiKey]
An enrolled YubiKey (`just yubikey <login>`) allows opening the session without
a password, handy while waiting for a reset. See
[Strong authentication](/en/doc/admin-guide/operate/yubikey/).
:::
