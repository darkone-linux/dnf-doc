This site is built with [Astro](https://astro.build/) and
[Starlight](https://starlight.astro.build/). Pages live under
`src/content/docs/<lang>/` (`fr`, `en`).

{/* t:p 6b83178770c6b771dd3f8d6dca700e1b49f544533bc67292d6df88fb12140963 */}
## Where to write

- `doc/<section>.mdx` : **entry page** of a section, introduction + links.
- `doc/<section>/<feuille>.mdx` : **detail pages**.
- Short cross-cutting topics → `doc/how-to/{user,admin,dev}/`.

Write in **French** (`fr/`) ; English is produced afterwards by
`just translate`. Slugs and file names stay in English.

{/* t:p 2bc5be94c96c567dc98778689d5237fe6b378aa15fc77fdfe15c869b54a8701e */}
## Essential Rules

- Max 7 headings per level, depth 3.
- `<Steps>` for step sequences, `<Aside>` (with title) for callouts.
- `Card`/`CardGrid` are reserved for the user guide.
- See the [help & how-to dev](/en/doc/how-to/dev/) and role *skills*.

## Tools

```sh
just dev      # serveur de développement

just build    # construit le site statique
just test     # tests + validation des liens internes
```

## Languages and translation

We write **only in French** (`fr/`); English (`en/`) is **produced** by
`just translate`. Never edit `en/` by hand.

| Action | What to do |
|---|---|
| **Create** a page | In `fr/` only; do not run `just translate`. |
| **Move** a page | Move **both** languages together (files, verbatim), then `just tags`. |
| **Translate** | At the end of the work: `just tags` then `just translate`. |

Translation markers are managed by the scripts, **never by hand**:

| Marker | Role |
|---|---|
| `{/* t:main */}` | Source-of-truth file of a page. |
| `{/* t:translated-from <lang> */}` | Translated file (do not modify). |
| `{/* t:h <hash> */}` | Frontmatter hash. |
| `{/* t:p <hash> */}` | Paragraph hash (before each block). |

:::caution[Translated file = read only]
A file carrying `t:translated-from` is **never** modified: it is rewritten by
`just translate`. You edit the `fr/` source (`t:main`).
:::

:::note[Exception: the changelog]
`changelog/` pages are **generated in English** by `just update-changelog`
from the framework's `CHANGELOG.md` (one page per version, with a title written
by an AI agent), then translated into French by `just translate`. Both recipes
run within `just update`. Do not edit these pages.
:::

## Links and anchors

- Internal links use `/fr/...`; they are validated at build time by
  `starlight-links-validator`.
- An **anchor** = *github-slugger* slug of the target heading text
  (`## Mon Titre` → `#mon-titre`).
- Check: `just build` (fails on a dead link) or `just check-links`.
- Broken anchor at build time (`invalid hash`) → fixed by `just build-fix`
  (AI agent, 3 attempts max), which `just update` runs.

## Making nice pages

The validated recipe: short items, colored callouts, `<Steps>`, tables,
D2 diagrams, generic examples. To follow depending on the persona&nbsp;:

| Persona | Tone |
|---|---|
| **User** | Make them want it, no jargon; `Card`/`LinkCard` allowed. |
| **Administrator** | Precise, operational; tables and callouts. |
| **Developer / AI** | Hierarchy (where → detail), step by step, concise. |

:::danger[Public data]
This documentation is **public**: never private network data (`../`).
Use generic examples (`domain.tld`, documentation IPs).
:::
